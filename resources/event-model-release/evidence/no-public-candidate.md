# No public event model selected

2026-10-18: No event model has completed the public distribution review and target qualification recorded by this repository. The initial catalog is intentionally empty and does not identify, approve, copy or publish any private pack.

Version 0.17.11 remains a model-free release. This selection-policy foundation is a separate follow-up; it does not modify that release tag or its workflow inputs. Future application versions must review their catalog and update the explicit lock rather than inheriting a floating model reference.

The future selection and packaging work is tracked in https://github.com/Kou-ISK/sportaglytics/issues/243 and docs/event-model-release-policy.md. This note is a no-model decision, not model-distribution permission or accuracy evidence.
