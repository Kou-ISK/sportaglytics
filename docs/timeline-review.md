# Timelineで場面を探す

Timeline下部の「場面を検索」または`Cmd/Ctrl+F`でレビュー欄を開きます。映像は独立したウィンドウに表示したまま、保存済みの行名・ラベル名とグループ・ノートを検索できます。アクションを記録するCode Windowとは役割が異なります。

- 空白で区切った語はすべて一致する場面を探します。英字の大文字・小文字と全角・半角は区別しません。
- 結果は開始時刻順、40件ずつ表示します。件数と前後ページを表示し、40件を超えた結果も確認できます。
- 入力中のEnterは先頭の結果を選択します。結果のクリックまたはTabで移動してEnterでも選択できます。選ぶと映像へ移動し、広幅では該当Timeline行/時刻も表示します。再生/停止の状態は維持します。「Timelineで表示」はレビューを閉じて該当箇所を表示します。通常のTimelineアクションのクリックは従来どおり選択だけです。
- 下部の詳細欄で、選択した1件の行名・時刻・ラベル・ノート全文を確認します。長文は折り返しとスクロールで読めます。「編集」は既存の編集ダイアログ、「Playlistに追加」は既存のPlaylist追加を実行します。複数選択中は1件の詳細を表示しません。
- レビュー内でEscを押すと語をクリアし、空欄でEscを押すとレビューを閉じてフッターのボタンへフォーカスを戻します。×でも閉じられます。日本語変換の確定中はEnter/Escを検索操作として扱いません。
- タグがない場合はCode Windowで開始・終了する案内、一致しない場合は検索のクリアと再検索を案内します。保存データから消えた場面や、検索語の変更で結果外になった場面はレビュー詳細に保持しません。文書の選択は維持し、古い詳細からの編集/Playlist追加を防ぎます。

レビューは起動時に閉じています。幅が880pxを超える編集領域では左側に最大320pxの欄を表示し、狭い領域では検索とTimelineを切り替えます。最小高さではレビュー全体もスクロールして詳細操作へ進めます。閉じると元のTimelineへ戻り、映像ウィンドウの寸法は変えません。レビューを閉じた状態では既存の行表示高さを維持します。

Tab/Shift+Tabは通常のフォーカス移動です。同じ行の前後の場面へジャンプするには、選択してTimelineにフォーカスした状態で`Option/Alt+↓` / `Option/Alt+↑`を使います。検索入力中・編集ダイアログでは文字入力を優先します。

検索・閉じる・「詳細へ移動」はレビュー上部に固定します。詳細への入口で40件の結果をTabで通過せず、詳細へフォーカスを移せます。結果のaccessible descriptionはラベル/ノートを含みます。最小高さでは詳細の見える量は少ないため、長文確認にはウィンドウを縦に広げると読みやすくなります。

レビューを閉じている間は検索の全件走査/ソートを行いません。検索語・ページ・開閉はウィンドウ内の一時状態で、パッケージへ保存しません。検索で行や区間を削除・非表示にせず、書き出しの対象を暗黙に絞りません。編集・Playlist追加・書き出しの保存対象はそれぞれの既存操作に従います。専用のチーム／種別フィルタはありません。検索語で名前やラベルを絞ります。

実装は`VisualTimeline/review`の純粋な検索関数、`useTimelineReview`、props-onlyの`TimelineReviewView` / `TimelineWorkspaceView`へ分離します。型・保存・IPCは既存のTimelineを使用します。Storybookの`Workspace/Timeline/Review`で多件・長文・空・該当なし・狭幅を確認でき、`scripts/e2e-ux-review.mjs`は既存の`run-electron-e2e.mjs`にも登録され、`pnpm run test:e2e`で他のシナリオと順に実行します。単独でもElectron上の検索・映像移動・編集・Playlist・分析入口・再開を検証できます。
