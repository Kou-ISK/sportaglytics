# 0064 Scoped Tab action navigation

## Status

Accepted

Supersedes [0055](0055-timeline-review-without-document-filtering.md) のTabキーボード判断のみ。検索・レイアウト・保存・IPCの判断は引き続き0055に従う。

## Date

2026-10-16

## Context

0055はDOMフォーカスと選択の不一致を避けるためTabの巡回を廃止したが、既存のアクションジャンプを利用していた操作を失わせた。0.16.1と削除前の実装では、選択された同一アクションを開始時刻順に巡回し、Shift+Tabで逆順、端で折り返していた。この操作を復元しつつ、入力やフォーカス移動、OSのキー組合せを保護する必要がある。

## Decision

選択が有効で、Timeline本体またはアクションタグにフォーカスがあるときに限り、修飾なしのTab／Shift+Tabで旧来の巡回・シークを行う。ジャンプ先のDOMフォーカスも更新し、選択だけが移って元のタグにフォーカスが残る状態を作らない。Escapeで選択を解除すれば通常のTab移動へ戻る。

入力・検索・ダイアログ・通常ボタン・行見出し・再生位置つまみ、Timeline外、無効な選択、IME変換中はTabを消費しない。Cmd/Ctrl/Alt+Tabを巡回に流用しない。Option/Alt+上下は既存の別名として残す。新しい設定やIPC、保存データの変更は追加しない。

## Consequences

旧来の操作を復元し、フォーカスの食い違いと無条件のTab捕捉を避ける。選択中はTabが巡回になるため、通常のフォーカス移動へ戻るEscapeをヘルプに明記する。回帰試験は前後移動・時刻順・折り返し・フォーカス・入力/OS修飾キーの除外をunitで、実映像へのシークとEscape後/検索入力の通常Tab移動をElectronで検証する。
