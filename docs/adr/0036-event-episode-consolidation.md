# 0036 Event Episode Consolidation

## Status

Accepted

## Date

2026-09-16

## Context

スクラム等の持続するプレーは短い映像窓で繰り返し検出され、固定間隔の重複抑制だけでは複数候補へ分割されます。抑制間隔を一律に広げると、間に通常プレーを挟む別イベントも失われます。RendererのTimeline結合では連続した信頼度を参照できず、手動編集の意図も区別できません。

## Decision

区間判定をmodel pack内に置き、密な信頼度の継続・谷の長さ・候補間隔・全体長をクラスごとに評価して固定します。連続する単一clip内だけで判定し、既存runner protocolの任意フィールド `detectedStartTime` / `detectedEndTime` を使用します。点検出だけの旧packは引き続き利用できます。

学習・調整の正本はprivate R&Dとし、明示的に確認したTrain区間とValidationの非劣化条件を使います。モデル重みの変更と区間判定の効果を区別し、後処理だけの変更でも評価設定とpack versionを更新します。Coding評価の代表時刻による判定は維持します。追加の確認済みフレームは実際の検出区間による包含も許し、一対一で確認します。

## Consequences

モデルが持つ時間方向の証拠で同一プレーをまとめられ、Rendererは既存の区間・lead/lag変換を共有できます。出力区間は厳密なイベント境界の保証ではありません。低いユーザーしきい値は未調整の単独候補を増やす場合があります。既存Timelineの削除・結合は行わず、別行での比較を案内します。未知試合の精度と作業時間削減を確認するまではexperimentalを維持します。
