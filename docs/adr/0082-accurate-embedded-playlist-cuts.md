# 0082 Accurate embedded playlist cuts

## Status

Accepted

## Date

2026-11-05

## Context

Playlist埋め込み保存で範囲指定後に圧縮映像をコピーすると、指定開始がキーフレーム以外の場合に次のキーフレームまでの映像が欠ける。音声と文書上の長さだけが残ることがあり、再読込や書き出しでは欠けた映像を復元できない。毎回変換し直すと、既存埋め込み素材の画質低下と保存時間が累積する。

## Decision

新規の埋め込み範囲は、対象映像と範囲に重なる音声を明示的に選んでH.264/AACへ逐次変換し、出力の時刻・尺・トラックを検査してからmanifestを公開する。元映像は変更しない。時刻の原点を移すときだけ描画時刻を同じ分だけ移す。

Mainがロードして受け付けた埋め込み文書について、項目・範囲・両アングル・素材の実体が一致する場合は素材を再利用する。別名保存では新しい専用領域へ排他的にコピーする。文書世代、入力素材または保存先manifestが処理中に変われば公開せず、既存manifestを保持する。

## Consequences

新規変換は時間と一時領域を要し、映像・音声を再圧縮する。音声の時刻を判定できない素材や出力の検証に失敗した素材は、欠落を隠して保存せずエラーとする。過去に欠落した素材を自動復元するものではない。ソフトウェアFFmpegの合成検証、各OSの実エンコーダー、GUI、署名済み配布版の検証は区別する。
