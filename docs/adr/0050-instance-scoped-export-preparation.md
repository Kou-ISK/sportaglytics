# 0050 Instance-scoped export preparation

## Status

Accepted

## Date

2026-09-22

## Related ADRs

- Supersedes: [0043 Bounded Lossless Export](0043-bounded-lossless-export.md)
- Extends: [0049 Bounded export text](0049-bounded-export-text.md)

## Context

離れた複数インスタンスの包絡区間を一時合成すると、出力しないプレーや同期空白までエンコードし、文字やPaintの合成でさらに再圧縮する。元ファイルごとに処理すれば不要になる準備が、前半と後半を選択しただけで発生する。品質設定を下げず、処理対象と再圧縮回数を減らすことを優先する。

## Decision

- 全必要ファイルの事前確認後、選択インスタンスと使用ソースの組ごとに要求範囲を計画する。離れたインスタンス間は合成しない。同じソース・同じ開始終了の準備だけを共有する。出力順、別々のノート・Paint、同じIDの再登場は維持する。
- 一つの元ファイルに収まるインスタンスは元映像を直接参照する。インスタンス自体がファイル境界や欠落区間をまたぐ場合だけ、その選択範囲を従来の合成経路へ渡す。必要な黒画面・無音は残す。
- 素材の時刻原点をインスタンスとアングルに所属させ、単一の物理ファイル名をキーにして上書きしない。同じファイルを異なる時刻に再利用しても原点が混ざらない。Paint・フリーズはインスタンス相対時刻のまま、入力シークだけを元ファイル時刻へ変換する。
- ADR 0043のコピー適合条件を維持する。全ファイル、または音声・Bフレームなしで両端キーフレーム確認済みの区間だけをコピーする。連結はストリーム構成・コーデック初期化情報・時刻基準等を確認し、不明なら再エンコードする。完成した1本は上書き禁止のコピーで保存する。
- Mainの共通計画・実行層でTimelineとPlaylistへ適用する。IPC検証と専用進捗Windowを維持し、一時生成物は失敗時にも回収する。解像度・圧縮設定を落とす最適化、並行実行、永続キャッシュは追加しない。

## Consequences

複数元映像から離れた場面を出力する際、準備量を包絡区間ではなく選択範囲へ制限できる。直接参照できる映像は事前の再圧縮を避けられる。一つの長いインスタンスが境界や空白をまたぐ場合、準備と描画の2段階は残る。単一ファイル内の通常の書き出しは大幅に速くなるとは限らない。

開始終了が異なり、互いに重なる境界越えのインスタンスは個別に準備するため、同じ画素を重複処理する場合がある。範囲を再び包絡区間へ広げるのではなく、今後の計測に基づいて1回の合成や安全なキャッシュを検討する。

文字やPaintの焼き込みには映像の再エンコードが必要で、元の圧縮データと完全一致する保証にはならない。速度と変更部分以外の画質は合成素材で比較し、環境依存の秒数をテスト合否には使わない。要求範囲・入力原点・Paint・同期空白・尺・音声と、エンコード回数の削減を検証する。

利用仕様は[高速書き出し](../user-guide.md#元の画質を保つ高速書き出し)、調査と計測条件は[書き出し性能レポート](../reports/2026-09-export-performance.md)を参照。
