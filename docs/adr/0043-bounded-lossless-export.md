# 0043 Bounded Lossless Export

## Status

Accepted

## Date

2026-09-21

## Related ADRs

- Extends: [0040 Shared Media Timeline Clock](0040-shared-media-timeline-clock.md)

## Context

同期済みアングルの全長を毎回合成すると、短い区間の出力でも長い準備が必要になり、進捗の対象外では停止したように見える。完成した映像の保存や互換ファイルの連結で再度エンコードすると、処理時間と画質劣化も増える。一方、圧縮映像は任意の位置でコピー切断するとキーフレーム、Bフレーム、音声パケットによって選択区間や同期が変わる。

## Decision

- 事前確認後に、ソースごとの選択範囲の包絡区間を計算する。1本の元ファイル内に収まる場合は直接使用し、必要な場合だけ空白を含む範囲を一時合成する。準備にもFFmpegの実時刻による進捗通知を適用する。
- 準備済み映像の共通時刻上の原点を内部状態として保持する。描画・フリーズはクリップ相対時刻を維持し、主映像と第2映像の入力シークへそれぞれの原点を適用する。
- 全ファイルまたは確認済みの安全な境界だけをコピー対象とする。部分切断は音声・Bフレームなし、両端キーフレーム確認済み（末尾を除く）に限定する。判定不能・任意フレーム・描画・静止挿入・2画面は正確なシークとエンコードへ戻す。選択時刻を丸めて高速化しない。
- 連結はストリーム構成、コーデック初期化情報、サイズ、time base等の互換性を確認してコピーする。concat demuxerの時計を維持し、音声primingによって映像をずらさない。互換性不明ならエンコードする。完成済みの1ファイルは上書き禁止のファイルコピーで保存する。
- 最適化はMainの共通経路へ置く。TimelineとPlaylistに別実装を作らず、設定UIは情報表示を切り替えるだけとする。

## Consequences

- 互換素材の全区間連結では圧縮データを保持でき、短い出力で試合全長を生成しない。Paintや空白がある出力の再エンコードは引き続き必要となる。
- 包絡区間内の未選択部分も準備対象になる。離れた多数の区間を独立生成する最適化や、GOP境界だけを再エンコードするsmart renderingは本判断の対象外とする。
- 進捗は処理範囲に基づく重みであり、異なる処理段階の残り時間には比例しない。コーデック・GPU・保存先に依存する固定の高速化倍率は保証しない。
- 合成素材の全フレームハッシュ、PTS原点、尺、空白、部分切断、準備進捗を実FFmpegで検証する。OSごとの同じ試験を維持する。
