# 0017 Row-owned timeline presentation

## Status

Accepted

## Date

2026-08-02

## Related ADRs

- Supersedes: N/A
- Superseded by: N/A

## Context

タイムラインの行は `actionName` ごとにインスタンスから動的生成され、色も各インスタンスの `color` から決めていた。このため、空行を保持できず、同じ行で色が不揃いになり、別の行へ移動したインスタンスにも移動前の色が残った。Sportscodeに合わせた行追加・名称変更・色変更には、インスタンスと独立した行モデルが必要である。

## Decision

- `timeline.json` の現行保存形式を `version: 2` のドキュメントとし、順序付きの `rows[]` と `instances[]` を保存する。
- 行は `id`、`name`、`color` を持ち、表示色と表示順の正本とする。インスタンスの `color` は旧配列形式および外部出力との互換用に残す。
- 旧配列形式はロード時に最初に現れるアクション順で行を導出する。ユーザーが編集するまではファイルを自動移行しない。
- 行移動時はインスタンスの `actionName` と互換用 `color` を移動先の行へ合わせる。行名または色の変更時は、その行の全インスタンスも同時に更新する。
- 空行の追加、行ラベルのEnter・ダブルクリック・コンテキスト操作による編集を許可する。
- 行ヘッダーを選択対象とし、通常クリックで単一選択、`Command`クリックで複数選択する。行ヘッダーのドラッグで表示順を変更し、キーボード操作用にコンテキストメニューからの上下移動も提供する。
- 選択行の削除は確認後に所属インスタンスと行をまとめて削除する。インスタンスの選択と行の選択は同時に保持せず、貼り付け先を曖昧にしない。
- インスタンスの通常ドラッグは別行への移動、`Option`ドラッグはコピーとする。`Command+C`でコピーしたインスタンスは、単一選択された行へ`Command+V`で元の時間範囲を保持して貼り付け、行名と色だけを貼り付け先へ合わせる。
- 手動インスタンス作成と既存インスタンスの長さ調整は `Option + Command` を押しながらドラッグする。SportscodeではCaps Lock編集モードを併用する経路があるが、本アプリは独立したCaps Lockモードを持たないため修飾キーの組み合わせを再現する。

## Consequences

- インスタンスが0件の行もパッケージの再起動後に復元できる。
- 行の背景と全インスタンスが同じ色になり、別行へ移動すると移動先の色へ変わる。
- 行選択には色だけでなく選択線と`aria-pressed`を使い、ドラッグできない場合もコンテキストメニューから並べ替えと削除を完結できる。
- `timeline.json` を直接読む内部処理は旧配列とversion 2の両方を受け付ける必要がある。JSON/CSV/SCTimelineの明示的なエクスポート契約は従来どおりインスタンス中心とする。
