# 0038 Detached event detection window

## Status

Accepted

## Date

2026-09-20

## Context

メイン映像ウィンドウは映像配置の縦横比を維持するため、大きな解析設定モーダルを載せると操作がスクロールに埋もれる。別ウィンドウ化しても、パッケージとTimelineの状態源を複製すると、背景での手修正と検出結果が競合する。

## Decision

Package Sessionごとに設定・進捗・結果を表示する独立ウィンドウを一つ持つ。Main processはその所有関係と表示状態を管理し、既存の映像Rendererが実行・取消・Timelineへの反映を引き続き所有する。

子Rendererは検証済みsnapshotをprops-only Viewへ渡し、小さな型付きコマンドのみを所有元へ送る。IPCの送信元をSessionの所有元または対応する子に限定する。別Sessionや他の補助ウィンドウからの操作を受け付けない。

閉じるボタンで非表示にしても実行を継続できる。所有元の終了・映像構成の変更で実行を取消し、遅れて届いた結果を破棄する。成功時の重複判定には実行開始時のコピーではなく、その時点の最新Timelineを使う。

## Consequences

映像比率を維持したまま解析設定を広く表示できる。設定フォームの状態源は増やさず、子を再表示しても実行と結果を保持する。子の再読込にはsnapshot再取得が必要で、購読中の更新を古い初期応答で上書きしない。処理はアプリ終了後に再開できる永続ジョブではない。
