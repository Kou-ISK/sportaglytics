# 0049 Bounded export text

## Status

Accepted

## Date

2026-09-21

## Context

ノートを全行表示するために文字を無制限に縮小すると、読みやすさを失い、背景が映像の約半分を覆う。映像を見ながらコーチングポイントを読めることを優先し、出力前に全クリップを確認する必要がある。ノートの保存・移行契約は[ADR 0048](0048-playlist-instance-notes.md)を維持する。

Hudl Sportscodeの[現行機能一覧](https://www.hudl.com/products/sportscode/tiers)はコード名・ラベル・ノートの重畳表示を説明する。[2026-03-17の更新履歴](https://www.hudl.com/releases/sportscode)はウィンドウサイズに依存しない高解像度のテキスト出力を説明する。[2021年の比例表示の説明](https://www.hudl.com/blog/hudl-pro-suite-update-sportscode-xml)も参考にする。2026-09-21の調査で現行版の高さ・最小文字サイズの数値は確認できなかったため、以下はSporTagLyticsの設計値とし、Sportscodeの数値仕様とは扱わない。

## Decision

- すべてのテキストを合わせて映像高の20%以内とする。下端に必要な高さだけ背景を描き、最低14%の帯は設けない。
- フォントは1080p換算30pxから24pxまで縮小する。行送りは文字サイズの1.25倍、上下余白は映像高の各1%。画面サイズではなく実際の出力解像度と縦横比から算出する。
- 明示的改行、空行、日本語の折り返しを保持し、結合文字・絵文字の途中で改行しない。タイトル・ラベルも同じ高さ予算に含める。
- 上限に収まらない場合は該当クリップを示し、本文編集または出力する項目の変更を求める。切り捨て、省略、24px相当未満の縮小、黙って文字を出力しない挙動は採用しない。
- 共通の純粋なレイアウト計算を正本とし、Mainで映像の構成とサイズを解決する。プレビューは実際のクリップ先頭に、出力と同じFFmpegのテキストフィルターを適用してから表示用に縮小する。Paintとフリーズはこの配置プレビューの対象外と明示する。
- 全クリップ・全出力アングルを確認し、読み込み中・失敗・超過中はUIから書き出せない。Mainでも保存先選択前に再検証し、Rendererだけを信頼しない。

## Consequences

長文を記録すること自体は制限しないが、読める状態で動画に焼き込める量には上限がある。文章量が多い場合はノートの編集、項目の除外が必要になる。複数アングルでは合成後の映像全体に一つの帯を表示する。プレビューは静止画生成分の待ち時間を伴うため、読み込み・再試行を表示し、古い要求の結果を適用しない。

[Playlist仕様](../playlist-features.md#ノートの編集と映像出力)を利用者向けの正本とする。これはADR 0048のノートモデルを変更せず、長文の表示制約を追加する判断である。
