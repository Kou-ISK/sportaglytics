# 0081 Held reverse presentation

## Status

Accepted

Supersedes [0080 Apple player playback](0080-apple-player-playback.md).

## Date

2026-11-01

## Context

AVPlayerへの毎画面更新の厳密シークは、次のseekIdによって描画待ちの有効画像を失効させる。描画が追いつかない状況では返却画像が全件有効でも押下中の表示が0枚になり得る。転送枠やキャッシュを増やしても要求寿命の問題は解消しない。解放時の最後の要求を残すだけでは、押下中にプレーを見て分析する目的を満たさない。

## Decision

0080のAVPlayerによる原本・音声・時計の所有、既存DOMへのIOSurface表示、CVPixelBufferをReleasedまで保持する境界を継承する。対応itemではready後のslow/fast reverse能力を確認し、開始または速度変更時の負rateを使う。押下時間に比例するシークを追加しない。実際の減少Drawn PTSを監視し、停止した表示を能力フラグやrateの成功で隠さない。指定速度の受入判定には区間全体の実PTSと実時計が別途必要になる。

画像配送ID・操作sequenceは増加を要求する一方、PTSと確認時計の向きは再生方向に従う。方向変更の最初の確認で進行検査を再基準化する。旧方向へ進んでから新操作が処理される遅延を、時計の偽造と混同しない。文書/source/seek/sequenceの所有検証は緩めない。

少しずつPTSが後退しても、実時計から大きく離れた画像列は追従成功ではない。既存の1秒の進行監視に加え、実時計と現在操作のDrawn PTSの差を要求倍率で割った時間にも同じ上限を適用する。v1の120000Hz単位で検査し、倍率に関係なく1 source秒で打ち切る仕様にはしない。音声設定の配送sequenceだけでは猶予を延長せず、明示seek・押し直し・方向/倍率変更を新しい待機として扱う。時計不明や無効な監視時刻は失敗として扱う。これは誤った成功判定の修正であり、復号速度や実画面の滑らかさの改善保証ではない。

能力非対応時の代替シークは現在の表示トランザクション1件と最新希望1件に分離する。表示トランザクションはIPCやseek完了だけでは解決せず、nativeのDrawn付きready、HTMLの元PTSとpaint待ちを含む。同じ長押しの新入力は現在の有効な画像を失効させず、別操作や素材変更はAbort/操作revisionで失効させる。連続負rateで開始済みの操作が失敗した場合、確認済み停止画像へ復帰して停止し、長押しを自動的にシーク反復へ変えない。

解放時は、連続逆再生ではpause後に実rate 0と停止画像を確認する。代替では新入力を止める。HTMLでは未発行の旧希望位置を破棄し、発行済みシークの提示を待つ。nativeのシーク代替では従来の最終希望位置を維持する。HTMLの短い再押下は先行画像の確定位置から扱う。いずれも開始位置や古い表示位置へ巻き戻す追加シークを行わない。タグ/保存/出力には確認時計を使う。Playlistの項目下限、clip/空白、各angleの時差と既存のキー制限は維持する。

停止後のvideo outputが実際の停止時計と異なる古い画像を返す場合は、その画像をreadyとして配送しない。同じsourceの一停止について一度だけoutputを再作成し、実際の停止時計へexact seekする補正を許容する。古い描画位置への巻き戻しではない。補正の完了通知だけでは成功にせず、既存v1適格profileの名目フレーム区間とPTS、現在操作のDrawnを確認する。再押下は進行中の補正callbackを無効化せず、新しい明示seekとcloseは無効化する。5秒の画像確認期限を補正で延長せず、未知/不一致は失敗停止とする。任意VFR素材のフレーム区間や物理画面提示の保証へ拡張しない。

終端自体/終端の先の画像PTSは許容せず、自然終了時計と最後の有効画像を区別する。自然終了の時計を画像時刻へ書き換えない。確認済みの移動は前の停止期限を終了し、次の停止をその時点から測る。単なる待機中の更新は期限を更新しない。

macOSのCommand修飾付き左キーは、フォーカス中のローカル入力をMainで受け取り、ウィンドウ・文書・操作世代に束縛する。Rendererへの配送確認と停止画像の確認は別の証拠とし、配送失敗時は捕捉した所有者を終了する。通常操作は古い入力を失効させ、終了確認後に最新の操作を原本側へ引き継ぐ。全局キー監視や新たなシステム権限は使わない。

## Consequences

通常操作に方式選択や新設定を追加しない。非対応素材の代替は復号性能に応じて表示間隔が変わり、画像確認が失敗した場合はエラーで停止する。元PTSを確認できないHTML埋込みは表示成功として扱わない。短い合成映像のLinuxブラウザ検証はAVPlayerや長尺実原本の滑らかさの証明にはならない。[仕様](../native-playback.md)と[検証・測定手順](../reports/2026-11-held-reverse.md)を参照する。
