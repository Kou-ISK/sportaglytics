# 0081 Held reverse presentation

## Status

Accepted

Supersedes [0080 Apple player playback](0080-apple-player-playback.md).

## Date

2026-11-01

## Context

AVPlayerへの毎画面更新の厳密シークは、次のseekIdによって描画待ちの有効画像を失効させる。描画が追いつかない状況では返却画像が全件有効でも押下中の表示が0枚になり得る。転送枠やキャッシュを増やしても要求寿命の問題は解消しない。解放時の最後の要求を残すだけでは、押下中にプレーを見て分析する目的を満たさない。

## Decision

0080のAVPlayerによる原本・音声・時計の所有、既存DOMへのIOSurface表示、CVPixelBufferをReleasedまで保持する境界を継承する。対応itemではready後のslow/fast reverse能力を確認し、開始または速度変更時の負rateを使う。押下時間に比例するシークを追加しない。実際の減少Drawn PTSを監視し、停止した表示を能力フラグやrateの成功で隠さない。指定速度の受入判定には区間全体の実PTSと実時計が別途必要になる。

画像配送ID・操作sequenceは増加を要求する一方、PTSと確認時計の向きは再生方向に従う。方向変更の最初の確認で進行検査を再基準化する。旧方向へ進んでから新操作が処理される遅延を、時計の偽造と混同しない。文書/source/seek/sequenceの所有検証は緩めない。

能力非対応時の代替シークは現在の表示トランザクション1件と最新希望1件に分離する。表示トランザクションはIPCやseek完了だけでは解決せず、nativeのDrawn付きready、HTMLの元PTSとpaint待ちを含む。同じ長押しの新入力は現在の有効な画像を失効させず、別操作や素材変更はAbort/操作revisionで失効させる。連続負rateで開始済みの操作が失敗した場合、確認済み停止画像へ復帰して停止し、長押しを自動的にシーク反復へ変えない。

解放時は、連続逆再生ではpause後に実rate 0と停止画像を確認する。代替では新入力を止めて最後の希望位置を表示する。いずれも開始位置や古い表示位置へ巻き戻す追加シークを行わない。タグ/保存/出力には確認時計を使う。Playlistの項目下限、clip/空白、各angleの時差と既存のキー制限は維持する。

## Consequences

通常操作に方式選択や新設定を追加しない。非対応素材の代替は復号性能に応じて表示間隔が変わり、画像確認が失敗した場合はエラーで停止する。元PTSを確認できないHTML埋込みは表示成功として扱わない。短い合成映像のLinuxブラウザ検証はAVPlayerや長尺実原本の滑らかさの証明にはならない。[仕様](../native-playback.md)と[検証・測定手順](../reports/2026-11-held-reverse.md)を参照する。
