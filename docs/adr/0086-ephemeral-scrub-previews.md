# 0086 Ephemeral Scrub Previews

## Status

Proposed

## Date

2026-11-19

## Context

ドラッグ中の正確なシークは、長いGOPの途中で前方復号を待つ。近似シークの許容幅を広げると、編集位置から離れた画像を表示し得る。通常の再生・音声・書き出しには元の素材を使用する。

## Decision

macOSのパッケージ主画面で、停止中の単一ローカルMP4を対象にする。Mainはバインド済み設定から素材を特定し、1080p・約60fpsのBT.709 H.264、映像開始0、最大96映像パケット内に24枚以上の非キーフレームが連続する場合に限って準備する。停止位置の前後約4秒を、同梱FFmpegで640×360の独立したJPEGフレームへ一度だけ復号・圧縮する。配布物への外部エンコーダー追加は不要。原本の開いた記述子、素材世代、設定の照合はMainが担当する。各フレームは原本の絶対PTSと結合し、区間の開始位置を再加算しない。

Rendererはドラッグで要求された原本時刻を含むフレームだけを重ねる。表示を始める前に素材の一致を再確認する。クリップの配置・同期が単純でない場合、プレイリスト、native再生、範囲外、準備失敗では既存のシークを使う。離した位置は元の映像要素で確定する。

## Consequences

準備待ちは開く操作と再生の前提にしない。プロデューサーと保持範囲はアプリ全体で各1件。圧縮データは最大12 MiB、最大480枚、ディスクへのキャッシュ書き込みなし。IPC転送の作業メモリとデコーダーのメモリは別に必要になる。作業を取り消した場合も子のcloseまで生成枠を保持する。全尺変換、永続proofの再利用、タグや書き出しへの代理映像の供給は対象外。
