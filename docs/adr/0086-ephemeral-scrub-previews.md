# 0086 Ephemeral Scrub Previews

## Status

Proposed

## Date

2026-11-19

## Context

ドラッグ中の正確なシークは、長いGOPの途中で前方復号を待つ。近似シークの許容幅を広げると、編集位置から離れた画像を表示し得る。通常の再生・音声・書き出しには元の素材を使用する。

## Decision

macOSのパッケージ主画面で、停止中の単一ローカルMP4を対象にする。Mainはバインド済み設定から素材を特定し、1080p・約60fpsのBT.709 H.264、映像開始0、最大96映像パケット内に24枚以上の非キーフレームが連続する場合に限って準備する。停止位置の前後約4秒を、同梱FFmpegで640×360の独立したJPEGフレームへ一度だけ復号・圧縮する。配布物への外部エンコーダー追加は不要。原本の開いた記述子、素材世代、設定の照合はMainが担当する。各フレームは原本の絶対PTSと結合し、区間の開始位置を再加算しない。

Rendererはドラッグで要求された原本時刻を含むフレームだけを重ねる。表示を始める前に素材の一致を再確認する。クリップの配置・同期が単純でない場合、プレイリスト、native再生、範囲外、準備失敗では既存のシークを使う。離した位置は元の映像要素で確定する。ローカルクリップ間の切替では同じ映像要素を保ち、切替先のメタデータが読めた時点から最初の提示フレームを監視する。停止中の正確なシークでは、切替先のメタデータを確認してから対象要素に元映像時刻を設定する。Video.js が canplay まで初回の要求を保留しても、提示フレームと要求の対応を追跡できる。

## Consequences

準備待ちは開く操作と再生の前提にしない。プロデューサーと保持範囲はアプリ全体で各1件。元映像の再生開始で生成中の処理を中断する。Rendererは画像復号がタイムアウトしてもその復号が終了するまで次の画像復号を開始せず、ドラッグ解放で表示中のプレビューを外す。圧縮データは最大12 MiB、最大480枚、ディスクへのキャッシュ書き込みなし。IPC転送の作業メモリとデコーダーのメモリは別に必要になる。作業を取り消した場合も子のcloseまで生成枠を保持する。全尺変換、永続proofの再利用、タグや書き出しへの代理映像の供給は対象外。

関連: [需要駆動区間の設計](0077-demand-driven-playback-ranges.md)。

クリップ切替後、停止中に同一時刻へのシークが重複すると、合成器はフレームを再提出しない場合がある。切替先の素材世代で観測した画像に限り、要求開始と読み込み開始の両方より後の提示時刻、厳密に一致するPTS、停止中の現在位置を照合する。近傍のPTSには従来のシーク順序検査を適用し、両アングルが描画を終えるまで位置を確定しない。

### 2画面の開始ギャップ（独立した経路）

この経路は縮小プレビューを2本に広げるものではない。各1本のローカルクリップを2画面で表示中、すでに再生可能な1本目と、ギャップ直後に初めて読み込む2本目がある場合だけ、古いドラッグ要求をまとめて取り消す。2本目のデコーダーをマウントしたまま黒で隠し、双方の正しいソースと時刻の提示確認後に表示と記録用クロックを更新する。単独表示、手動同期、断片化MP4、複数クリップには適用しない。映像出力・角度オフセットは変更しない。

遠い位置への同期シークでは、コンポジタはJavaScriptの時刻代入が戻る前にも画像を提出する。確認済みの同一ソースに対する代入前後の位置が0.1秒より離れ、呼出し後に対象位置でシーク中である場合に限り、時刻順の境界をその操作の直前に置く。近い位置・進行中のシーク・代入時刻がない経路は従来の境界のまま。代入開始時刻と同時かそれ以前、対象外ソースのコールバック、許容範囲外のPTSでは確定しない。
