# 0037 Reviewed Model Refinement

## Status

Accepted

## Date

2026-09-16

## Context

確認済みの見逃しやイベントの取り違えに対してしきい値だけを下げると、別試合の不要な候補も増加します。一方、新しい試合だけで判定を学習し直すと過去の検出を失い、スコアの変化で同一プレーが再び分割される場合があります。検出数が同じでも以前拾えた別のイベントを失っている可能性があります。

## Decision

既存の特徴抽出・イベント判定を保持した補正学習をmodel packの選択肢とします。private R&Dで、過去のTrain映像・同期済み追加アングル・以前の確認済み例を継承し、過去の判定を保持する学習と新しい明示的レビューによる補正を組み合わせます。未確認区間は背景ラベルにせず、AIによる映像確認は根拠を残した弱い教師データとします。

補正後の区間判定も評価し、同一の検出済みCodingイベント、追加の確認済み地点、別イベントの分離、確認済み区間内の重複・誤判定を採用条件に含めます。学習重みの更新と後処理の変更は分けて記録します。製品は完成したpackを使用し、共通IPC・Timeline契約を維持します。

2026-09-17追記: 安定しているクラスのスコアをそのまま保持し、他クラスだけへ時間文脈の補正を適用できる設計とします。スクラムと似た隊形や通常のキックは単一の短い窓では区別しにくいため、同じclip内の前・中・後の特徴を使います。公開画像は静止した場面の補助教師として比較し、時刻を持つイベント教師とは分離します。画像を使わない候補も同じ条件で評価し、改善のない画像追加は採用しません。学習用の確認区間、選択用Validation、未使用Testを混ぜず、確認済みValidationの正例を二重検出する候補も拒否します。

## Consequences

元モデルの視覚特徴を一度だけ抽出して補正に再利用でき、製品へ学習環境や外部AI接続を持ち込みません。過去のデータを引き継いだ根拠と新checkpointを追跡できます。確認した試合に局所的な補正となる可能性があるため、Train/Validationの改善を未知試合の精度として表示しません。独立したTest評価と修正作業時間の確認まではexperimentalを維持します。実装・学習の正本はprivate R&Dの `docs/reviewed-kernel.md` と `docs/targeted-temporal.md`、製品の操作と契約は [event-detection.md](../event-detection.md) とします。
