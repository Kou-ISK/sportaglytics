## はじめに

SporTagLytics は、スポーツ映像のタグ付けと分析を効率化するElectronアプリケーションです。

### 主な機能

- **マルチアングル映像**: 最大8アングル、各16クリップの同期再生
- **音声同期**: 音響分析による自動オフセット調整
- **イベントタグ付け**: ワンクリックでイベント記録
- **ビジュアルタイムライン**: 波形表示で直感的なイベント編集
- **統計ダッシュボード**: ポゼッション、モメンタム、クロス集計
- **プレイリスト**: フリーズフレーム、描画、クリップ書き出し
- **カスタマイズ可能**: コーディングパネルの自由配置

## クイックスタート

### 1. パッケージ作成

1. メニュー → 「新規パッケージ」
2. パッケージ名とチーム名を入力
3. 各アングルの「＋」から「ローカル映像」または「YouTube」を選ぶ。ローカル映像は複数選択またはFinderからの複数ドロップに対応
4. 映像の順番はドラッグ、または上下ボタンで調整する
5. 「パッケージを作成…」を押し、保存先ディレクトリを選択して完了
6. 作成後にシンクモードを開き、基準クリップと配置対象クリップを選んで再生位置を合わせる。「この位置で配置」で共通タイムラインへ置き、「同期を適用」で配置を保存する。空白は再生時に黒画面・無音として表示される

YouTubeを含む音声微調整はmacOS 13以降で利用できます。操作時に表示中の再生音を15秒だけメモリ上で解析します。外部アプリの音が混ざらないようにし、権限を拒否した場合は手動配置を利用してください。映像・音声のダウンロードや一時保存は行いません。

**パッケージ構造**:

```
PackageName/
├── .metadata/
│   └── config.json             # 映像構成と同期データ
├── timeline.json
└── videos/
    └── sources/
        ├── angle-1/             # アングルごとの元クリップコピー
        └── angle-2/
```

### 2. 映像再生と基本操作

- **Space**: 再生/一時停止
- **←**: 0.5倍速逆再生（押下中）
- **Shift+←**: 2倍速逆再生（押下中）
- **Option+←**: 4倍速逆再生（押下中）
- **Command+←**: 6倍速逆再生（押下中）
- **→**: 0.5倍速再生（押下中）
- **シークバー**: クリックで移動

### 3. イベントタグ付け

1. アクションボタンをクリック（開始）
2. もう一度クリック（終了）
3. 自動的にタイムラインに追加

**ヘルプウィンドウの内容**:

| セクション             | 内容                                                 |
| ---------------------- | ---------------------------------------------------- |
| パッケージ管理         | 新規作成・既存パッケージを開く・最近開いたパッケージ |

| タグ付け               | アクション記録とラベル付け、ホットキー操作           |
| タイムライン編集       | イベントの編集・移動・複製・プレイリスト追加         |
| 統計ダッシュボード     | ポゼッション・モメンタム・クロス集計の可視化         |
| エクスポート           | タイムラインとクリップの入出力                       |
| プレイリスト           | プレイリスト専用ウィンドウで再生・メモ・描画         |
| 設定                   | テーマ・ホットキーの管理                             |
| ショートカット         | 再生・同期・分析・Undo/Redoなどの主要ショートカット  |

- ウィンドウ上部から機能名・操作名を検索可能

- キーボードショートカット一覧を確認可能
- トラブルシューティングのヒント
- ライト／ダークのシステム外観と狭いウィンドウ幅に自動適応

**ヒント**: 初めて使う機能がある場合は、まずヘルプウィンドウで該当セクションを確認することをおすすめします。

## パッケージ管理

### パッケージ作成ウィザード

| ステップ | 内容                                                     |
| -------- | -------------------------------------------------------- |
| 基本情報 | パッケージ名、チーム名                                   |
| 映像     | 最大8アングル、各16ローカルクリップまたはYouTubeクリップ |

映像ステップは、アングル一覧と選択アングルのクリップ一覧による2ペイン構成です。各アングルの「＋」から「ローカル映像」または「YouTube」を選びます。ローカル映像は一度に複数選択でき、Finderから複数ファイルをドロップすることもできます。YouTubeはURLを1本ずつ追加し、同じアングルへ繰り返し追加できます。ローカル映像とYouTubeは同一アングル内で混在できません。追加後のクリップはドラッグまたは上下ボタンで並べ替えられます。

同期位置は作成画面では指定しません。保存先は専用ステップではなく、最後に「パッケージを作成…」を押した時に選択します。

**自動処理**:

- 映像ファイルのコピー＆リネーム
- アングル・クリップ単位の仮想タイムライン作成
- メタデータ生成

作成後にシンクモードを開き、基準クリップと対象クリップをそれぞれ再生・シークして「この位置で配置」を押します。「同期を適用」すると、絶対開始位置と派生した空白時間が保存されます。ローカルアングルも元クリップをそのまま使い、空白区間ではプレイヤーを外して黒画面・無音を表示するため、同期のたびに再生用ファイルを作り直しません。

### パッケージ読み込み

- メニュー → 「パッケージを開く」
- ディレクトリを選択
- 設定とタイムラインが自動復元
- `tightViewPath` / `wideViewPath` だけの旧パッケージも、読み込み時に1アングル1クリップの現行構成へ移行されます。元クリップと旧再生用コピーが併存する場合は元クリップ参照へ切り替わります。安全のため、旧再生用コピー自体は自動削除されません

## 映像再生

### マルチアングル同期

- **表示**: 3アングル以上は映像領域内のグリッドで表示
- **クリップ配置**: 基準クリップと対象クリップの現在位置から、対象クリップの共通タイムライン上の開始位置を計算
- **ローカル映像**: 元クリップを仮想タイムライン上で切り替え、クリップ間の空白を再生時に黒画面・無音で表示。書き出し時のみ一時合成
- **YouTube**: 複数クリップを共通コントローラーとホットキーで操作可能。ネットワーク接続と動画側の埋め込み許可が必要
- **音声で微調整**: ローカル映像は指定区間を解析し、YouTubeを含む場合はmacOS 13以降で表示中の再生音を15秒だけ解析。低信頼度、権限拒否、非対応環境では手動配置を維持
- **手動同期モード**: メニュー「同期 > 手動同期モード」（`Cmd+Shift+T`）
- **同期リセット**: メニュー「同期 > 同期オフセットをリセット」（`Cmd+Shift+R`）
- **再解析**: メニュー「同期 > 自動同期（音声解析）」（`Cmd+Shift+S`）

### 再生コントロール

| 操作          | ショートカット       |
| ------------- | -------------------- |
| 再生/一時停止 | `Space`              |
| 0.5倍速逆再生 | `←`（押下中）        |
| 2倍速逆再生   | `Shift+←`（押下中）  |
| 4倍速逆再生   | `Option+←`（押下中） |
| 6倍速逆再生   | `Cmd+←`（押下中）    |
| 0.5倍速再生   | `→`（押下中）        |
| 2倍速再生     | `Shift+→`（押下中）  |
| 4倍速再生     | `Cmd+→`（押下中）    |
| 6倍速再生     | `Option+→`（押下中） |

※ 早送りはキーを離すと通常速度（1.0x）に戻り、逆再生はキーを離した位置で一時停止します。

## イベントタグ付け

### 基本操作

1. **開始**: アクションボタンを1回クリック
2. **終了**: 同じボタンを2回目クリック
3. **保存**: 自動保存

### コーディングパネル編集

**自由配置エディタ（FreeCanvasEditor）**:

- ドラッグ&ドロップで自由配置
- `Shift`/`Cmd`+クリックで複数選択
- グリッドスナップ（10px）
- キャンバスサイズ調整（400-2000px × 300-1500px）

**リンク作成**:

1. 右クリック+ドラッグでリンク作成
2. リンク種別選択:
   - `exclusive`（赤）: 排他的遷移
   - `activate`（緑）: アクティベート
   - `deactivate`（オレンジ）: ディアクティベート
   - `sequence`（青）: シーケンス
3. `Delete` キーで削除

**Undo/Redo**:

- `Cmd+Z`: 元に戻す
- `Cmd+Shift+Z` / `Cmd+Y`: やり直し

## タイムライン編集

### テーブル表示

- ソート機能（アクション名、時刻）
- インライン編集（結果、種別、修飾子）
- 映像ジャンプ（開始/終了時刻ボタン）
- 複数選択削除

### ビジュアルタイムライン

- 映像パッケージを開くと、映像ウィンドウとは別にタイムラインウィンドウが開きます。2画面へ分けて配置でき、閉じた場合は映像右上のタイムラインボタンから再表示できます
- 再生、速度変更、前後シークなどの設定済みホットキーは、映像とタイムラインのどちらにフォーカスがあっても同じ映像へ作用します
- 再生ヘッドは映像側の時刻を基準に滑らかに補間され、ドラッグ中のシークは映像へ連続反映されます

**ズーム**:

- `Cmd/Ctrl` + ホイールでズーム

**範囲選択**:

- `Shift` + ドラッグで複数選択

**操作**:

- クリック: 選択＋ジャンプ
- ダブルクリック: 編集ダイアログ
- 右クリック: コンテキストメニュー
- `Enter`: 編集
- `Delete`/`Backspace`: 削除
- 左下の`＋`: 空の行を追加
- 行ヘッダーをクリック: 行を選択。`Command`クリックで複数の行を選択
- 行ヘッダーをドラッグ、または右クリックメニューの「上へ移動」「下へ移動」: 行を並べ替え
- 選択行で`Delete`/`Backspace`、または右クリックメニューの「行を削除」: 確認後に行と所属インスタンスを削除
- 行ヘッダーで`Enter`、ダブルクリック、または右クリック: 行名と色を編集
- インスタンスを別行へ通常ドラッグ: 移動先の行へ移動。`Option`を押しながらドラッグするとコピー
- インスタンスを選択して`Command+C`、貼り付け先の行を選択して`Command+V`: 元の時間位置のまま当該行へコピー
- `Option+Command` + 赤い再生ヘッドをドラッグ: その行にインスタンスを作成
- `Option+Command` + インスタンス端をドラッグ: 開始・終了時刻を調整

### 検索・フィルタ

- テキスト検索
- チーム別フィルタ
- アクション種別フィルタ

### タイムラインのクリップ書き出し

- メニューから「クリップ書き出し」を選択
- 書き出し範囲（全体/選択中）と出力モード（1ファイル/インスタンス/アクション）を指定
- アングル（全アングル/単一/マルチ）を選択
- オーバーレイ設定は「設定 > 一般 > クリップ書き出しオーバーレイ」に従います
- 書き出しを開始すると設定ダイアログは閉じ、専用の進捗ウィンドウが開きます。進捗ウィンドウはメインウィンドウのフォーカスを奪わず、書き出し中も再生などの操作を継続できます

## 統計分析

### 統計・分析ウィンドウ（`Cmd+Shift+A`）

v0.4.0以降、統計・分析機能は独立したウィンドウで表示されます。

**現在のタブ（v0.5.0）**:

| タブ           | 内容                                                 | バージョン |
| -------------- | ---------------------------------------------------- | ---------- |
| ダッシュボード | カスタマイズ可能なウィジェット配置、テンプレート管理 | v0.4.0     |
| モメンタム     | ポゼッションの流れを棒グラフで可視化                 | v0.2.0     |
| クロス集計     | 任意の軸でヒートマップ表示、ドリルダウン             | v0.2.0     |
| AI分析         | ローカルLLMによる映像分析、推奨クリップ生成          | v0.5.0     |

**注**: ポゼッション・アクション結果・アクション種別タブはv0.4.0でダッシュボード機能に統合されました。これらの統計情報はダッシュボードのウィジェットまたはカスタムチャート機能で利用できます。

### クロス集計

**カスタマイズ可能な軸**:

- 行軸/列軸: アクション名、結果、種別、修飾子
- フィルタ: チーム別、アクション別
- 画面表示では文字サイズをコンパクト化し、同時に見える情報量を増やしています
- 2段ヘッダ時のスクロール固定を調整し、「合計」列だけ縦長に見える崩れを抑制しています

### ダッシュボード（v0.4.0以降）

**機能**:

- カスタマイズ可能なウィジェット配置
- デフォルトテンプレート（.stadパッケージ形式）
- シリーズ比較機能
- カスタムチャート作成
- 編集モード中はヘッダ操作を `チャート追加 / キャンセル / 保存` に集約し、管理操作とダッシュボード切替は一時的に無効化されます

### モメンタム

- 0基準線が画面中央に見えるよう、Y軸幅を考慮した左右余白で表示します
- 画面表示の目盛りは最小構成（`-max / 0 / +max`）にし、詳細はツールチップで確認します

### AI分析（v0.5.0以降）

**概要**:

AI分析機能は、ローカルLLM（llama.cpp）を使用して映像を自動分析し、質問に対する回答や推奨クリップを生成します。

詳細なセットアップとトラブルシュートは [AI Analysis and Local LLM Setup](ai-analysis.md) を参照してください。データ境界は [Privacy and Data Handling](privacy-and-data-handling.md) にまとめています。

- 右カラムは `根拠 / イベントインサイト（統計） / AI設定` のAccordion構成です（初期表示は根拠のみ展開）
- 根拠リストは初期表示を上位12件に制御し、必要に応じて全件展開できます
- 右カラム専用スクロールを廃止し、タブ全体で一貫したスクロール動作になります

**必要なセットアップ**:

1. **llama.cppバイナリ**:
   - **macOS**: 自動同梱（追加作業不要）
   - **Windows/Linux**: 手動配置が必要

2. **GGUFモデルファイル** (`.gguf`拡張子必須):
   - 配置場所: `public/llama/models/` ディレクトリ
   - 開発中: `public/llama/models/*.gguf`
   - パッケージ版: アプリリソース内の `llama/models/*.gguf`

**llama.cppバイナリの配置方法**:

アプリは以下の優先順位でバイナリを検索します：

1. **環境変数** (最優先):
   - `SPORTAGLYTICS_LLAMA_PATH`: SporTagLytics専用パス
   - `LLAMA_CPP_PATH`: 汎用llama.cppパス
   - 例: `export SPORTAGLYTICS_LLAMA_PATH="/usr/local/bin/llama-cli"`

2. **アプリ内蔵パス**:
   - パッケージ版: `<app>/Contents/Resources/llama/<platform>/`
   - 開発版: `public/llama/<platform>/`
   - `<platform>` = `darwin` (macOS) / `win32` (Windows) / `linux`

3. **バイナリ名の候補** (優先順):
   - `llama-completion`
   - `llama-cli`
   - `llama`
   - `main`
   - Windows: 上記に `.exe` 拡張子

**使い方**:

1. 統計・分析ウィンドウを開く（`Cmd+Shift+A`）
2. 「AI分析」タブを選択
3. テンプレートから質問を選択するか、自由にテキスト入力
4. 「実行」ボタンでAI分析を開始
5. 結果として以下が表示されます：
   - **要約**: 質問に対する簡潔な回答
   - **仮説**: データに基づく推論
   - **根拠**: タイムライン上の関連イベント（ハイライト表示）
   - **推奨クリップ**: AI が選んだ重要シーン

**プレイリスト作成**:

- 「プレイリスト作成」ボタンで、推奨クリップから自動的にプレイリストを生成できます
- 生成されたプレイリストは新しいウィンドウで開きます

**AI分析の仕組み**:

- **ハイブリッド根拠検索**: テキスト、ラベル、メモ、時間、レアラベルを組み合わせて関連イベントを抽出
- **グラウンディング**: タイムラインデータを基にした事実ベースの回答生成
- **ローカル処理**: 全てのデータはローカルで処理され、外部に送信されません
- **ストリーミング進捗**: 出力文字数とチャンクごとの進捗がリアルタイムで表示
- **タイムアウト制御**: デフォルト120秒（2分）、実行中のキャンセルも可能

**制限事項**:

- v0.5.0では macOS のみサポート（Windows/Linux版llama.cppバイナリは未同梱）
- モデルファイルは `.gguf` 拡張子で `public/llama/models/` に配置が必要
- 環境変数 `SPORTAGLYTICS_LLAMA_PATH` または `LLAMA_CPP_PATH` でバイナリパスをカスタマイズ可能

### 分析結果の出力

分析ウィンドウの export 操作から以下を出力できます。

| 出力                   | 内容                                                   |
| ---------------------- | ------------------------------------------------------ |
| 構造化サマリーをコピー | 現在の分析ビューの要約をクリップボードへコピー         |
| PNG保存                | 現在の分析ビューを画像として保存。長い内容は分割保存可 |
| 分析レポートPDF保存    | ダッシュボード、モメンタム、クロス集計をPDF化          |

詳細は [Analysis Report Export](analysis-report.md) を参照してください。

## プレイリスト機能

### プレイリスト作成

#### タイムラインからの追加（v0.2.0以降）

1. タイムラインからイベントを選択（複数選択可）
2. 右クリック → 「プレイリストに追加」
3. 開いている全てのプレイリストウィンドウに追加されます  
   （ウィンドウが開いていない場合は新規ウィンドウが自動で開きます）

- ツールバーのプレイリストボタンからも同じ操作が可能です
- 選択中のイベントは `Cmd+Shift+P` でもプレイリストに追加できます

#### AI分析からの追加（v0.5.0以降）

1. 統計・分析ウィンドウで「AI分析」タブを開く
2. 質問を入力し「実行」ボタンで分析
3. 「プレイリスト作成」ボタンで推奨クリップからプレイリストを自動生成
4. 新しいプレイリストウィンドウが自動的に開きます

**注意**: v0.5.0でプレイリスト作成方法が統一され、両方の方法とも同じElectron APIを使用するようになりました。

#### 複数ウィンドウ管理

- 同時に複数のプレイリストウィンドウを開くことができます
- 新しいウィンドウは自動的にカスケード表示されます（前のウィンドウから50pxずつオフセット）
- 同じ`.stpl`ファイルを複数回開こうとした場合は、既存のウィンドウにフォーカスします

### プレイリストファイル（.stpl）形式

プレイリストは `.stpl` 拡張子のパッケージ形式で保存されます。

**パッケージ構造**:

```
MyPlaylist.stpl/              # パッケージディレクトリ（Finderでは単一ファイルに見える）
├── playlist.json             # プレイリストメタデータ（テキストファイル）
└── videos/                   # 映像ファイル（埋め込み形式のみ）
    ├── パス_01JGXXX123ABC/   # <アクション名>_<itemId>
    │   ├── angle1.mp4        # プライマリ映像
    │   └── angle2.mp4        # セカンダリ映像（存在する場合）
    ├── シュート_01JGXXX456DEF/
    │   ├── angle1.mp4
    │   └── angle2.mp4
    └── ...
```

**形式の種類**:

- **埋め込み形式（embedded / スタンドアロン）**: 映像ファイルをFFmpegで切り出して`videos/`に保存、パッケージ単体で再生可能（大容量）
- **参照形式（reference）**: 外部映像ファイルへのパスを保存、軽量（元の映像ファイルが必要）
  - 元映像が移動/削除された場合、参照形式のプレイリストは再生できません

**保存時の選択**:

- 初めてプレイリストを保存する際、保存ボタンを押すと形式選択ダイアログが表示されます
- 既に保存されているプレイリストは、その形式で上書き保存されます
- 埋め込み形式では、クリップの開始時刻は`0秒`起点に変換されます（切り出し動画のため）

**ファイルの閲覧**:

1. Finderでプレイリストファイルを右クリック
2. 「パッケージの内容を表示」を選択
3. `playlist.json` をテキストエディタで開いて内容確認・編集可能

**未保存変更の管理**:

- ウィンドウタイトルに未保存変更がある場合は `*` マークが表示されます
- ウィンドウを閉じる際、未保存の変更がある場合は確認ダイアログが表示されます
  - 「保存」: 変更を保存してから閉じる
  - 「保存しない」: 変更を破棄して閉じる
  - 「キャンセル」: 閉じずにウィンドウを維持
- 保存した描画・フリーズ設定はプレイリスト読み込み時に復元されます

### プレイリストウィンドウ

**再生機能**:

- 連続再生
- ループ再生
- フリーズフレーム
- アングル表示切替（アングル1/アングル2/デュアル）
- 一時停止後の再生は現在位置から再開し、アイテム行の再生操作はそのクリップ開始位置から再生
- シーク位置は選択中クリップの開始・終了範囲内へ制限

**フリーズの挙動**:

- 描画のタイムスタンプに到達すると自動停止
- 設定したフリーズ時間の経過後に自動再開。再生ボタン/`Space`ですぐ再開することも可能

**コントロール表示**:

- コントロールは映像エリアにマウスをホバーした時のみ表示されます
- コントロールボタンとスライダーは小型化され、より邪魔にならないデザインになっています

**描画機能**:

- ペン、選択（ドラッグ移動・Delete削除）、矩形、円、線、矢印、テキスト
- 色選択、線幅調整
- Undo、全クリア
- 描画は「作成した時刻」に紐づき、再生中は該当時刻付近で表示されます
- デュアル表示中は描画対象（メイン/サブ）を切り替え可能

**メモ/選択**:

- チェックボックスで複数選択し、`Backspace`で一括削除
- メモはプレイリスト内のみに保存され、タイムラインには反映されません

### クリップ書き出し

**書き出しモード**:

- 1ファイル: 全クリップを結合
- インスタンスごと: イベント単位
- アクションごと: アクション種別単位

**書き出し範囲**:

- 全体
- 選択中アイテムのみ

**オーバーレイ**:

- アクション名、通番、ラベル、メモ
- 描画（アノテーション）とフリーズフレームを含めた書き出しに対応

**アングル**:

- 全アングル（アングルごとに個別書き出し）
- 単一アングル
- マルチアングル（2映像を並列）

**進捗表示**:

- 書き出し中は専用の進捗ウィンドウが表示されます
- メインウィンドウには進捗バーを出さず、書き出し中も通常操作を継続できます
- 進捗率と残り時間は、各クリップの完了件数ではなくFFmpegが処理した映像時間に追従します

## 設定

### 全般設定

- テーマ（ライト/ダーク/システム）
- クリップ書き出しオーバーレイ（表示/非表示、表示項目の切替）

### コードウィンドウ

- メニューバーの「ファイル > 新規 > コードウィンドウ…」（`Cmd+Shift+N`）から保存先を選び、空の `.stcw` を独立ウィンドウで開く
- 既存ファイルは「ファイル > 開く > コードウィンドウ…」（`Cmd+Option+O`）で対象の `.stcw` を選んで開く
- ボタン配置・プロパティ・リンクの編集と保存は、コードウィンドウ上部の「編集」から行う
- コード／ラベル／編集モードは対象のコードウィンドウ上部で切り替える。アプリ全体のメニューバーからは切り替えない
- 編集中もボタンの色、輪郭、文字サイズ、位置と寸法は実行時と同じ表示になる。選択中だけ編集用の輪郭とハンドルが追加される
- ウィンドウをリサイズしても保存キャンバスの寸法は変わらず、表示領域を超える場合はスクロールして編集する
- 設定画面は `.stcw` ファイルの管理に使用しない

### メニューバー

- 「ファイル」は映像パッケージとコードウィンドウの新規作成・選択、最近開いた映像パッケージ、インポート・エクスポートを扱う
- 「ウィンドウ」は分析・プレイリストウィンドウの表示と、最小化・拡大縮小・前面表示を扱う
- コードウィンドウは新規作成または `.stcw` 選択を起点とするため、対象が不明な「コードウィンドウを開く」は表示しない

### ホットキー設定

- カスタムホットキー登録
- 機能名またはキーによる検索
- 競合チェック
- デフォルトに戻す
- システム標準のショートカット（Cmd+Q等）は割り当て不可

## プライバシーとデータ

SporTagLytics は local-first の desktop app です。映像、タイムライン、プレイリスト、AI 分析プロンプトはローカルで処理され、現行実装では cloud sync、telemetry、remote analytics、cloud LLM provider は使いません。

保存場所、recent package、localStorage、AI 分析時の一時ファイル、issue 報告時の注意点は [Privacy and Data Handling](privacy-and-data-handling.md) を参照してください。

## トラブルシューティング

### 音声同期がうまくいかない

1. 両映像に音声が含まれているか確認
2. 手動オフセット調整を試す
3. メニュー「同期 > 自動同期（音声解析）」を実行して再計算

### 映像が再生されない

1. ファイル形式を確認（MP4/MOV推奨）
2. コーデックを確認（H.264推奨）
3. ファイルパスに日本語が含まれていないか確認

### タイムラインが保存されない

1. ディレクトリの書き込み権限を確認
2. ディスク容量を確認
3. `timeline.json` が破損している場合は削除して再作成
