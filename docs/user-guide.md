## はじめに

SporTagLytics は、スポーツ映像のタグ付けと分析を効率化するElectronアプリケーションです。

### 主な機能

- **マルチアングル映像**: 最大8アングル、各16クリップの同期再生
- **音声同期**: 音響分析による自動オフセット調整
- **イベントタグ付け**: ワンクリックまたはホットキーでイベント記録。Actionごとに記録開始前・終了後の秒数を設定可能
- **自動イベント検出**: 利用可能なローカルモデルでラグビーイベントを検出して通常のTimelineへ初期Coding
- **ビジュアルタイムライン**: 時間軸に沿ったイベント編集
- **統計ダッシュボード**: ポゼッション、モメンタム、クロス集計
- **プレイリスト**: フリーズフレーム、描画、クリップ書き出し
- **カスタマイズ可能**: コードウィンドウの自由配置

## クイックスタート

### 1. パッケージを開く / 作成する

起動画面の「最近開いたパッケージ」からクリックまたはEnterで再開できます。「履歴を検索」で名前・チーム・保存場所を絞り込めます。別のファイルは「パッケージを開く」か、`.stpkg`を1つドロップしてください。履歴末尾の×は履歴だけを除き、元ファイルは残します。

読み込み中は操作を抑止し、失敗時は画面内の「もう一度開く」から再試行できます。保存先やドライブを確認し、移動した場合は選び直してください。履歴の上限・ドロップ制約・復旧は[起動画面の仕様](start-workspace.md)を参照してください。

新しいパッケージを作成する場合:

1. 「新しいパッケージを作成」または ファイル > 新規 > パッケージ… を選択
2. パッケージ名とチーム名を入力
3. 各アングルの「＋」から「ローカル映像」または「YouTube」を選ぶ。ローカル映像は複数選択またはFinder / Explorerからの複数ドロップに対応
4. 映像の順番はドラッグ、または上下ボタンで調整する
5. 「パッケージを作成…」を押し、保存先ディレクトリを選択して完了
6. 作成後にシンクモードを開き、基準クリップと配置対象クリップを選んで再生位置を合わせる。「この位置で配置」で共通タイムラインへ置き、「同期を適用」で配置を保存する。空白は再生時に黒画面・無音として表示される

YouTubeを含む音声微調整はmacOS 13以降またはWindowsで利用できます。操作時に表示中の再生音を15秒だけメモリ上で解析します。外部アプリの音が混ざらないようにし、権限を拒否した場合は手動配置を利用してください。映像・音声のダウンロードや一時保存は行いません。

**パッケージ構造**:

```text
PackageName/
├── .metadata/
│   └── config.json             # 映像構成と同期データ
├── timeline.json
└── videos/
    └── sources/
        ├── angle-1/             # アングルごとの元クリップコピー
        └── angle-2/
```

### 2. 映像再生と基本操作

- **Space**: 再生/一時停止
- **←**: 0.5倍速逆再生（押下中）
- **Shift+←**: 2倍速逆再生（押下中）
- **Option+←**: 4倍速逆再生（押下中）
- **Command+←**: 6倍速逆再生（押下中）
- **→**: 0.5倍速再生（押下中）
- **シークバー**: クリックで移動

### 3. イベントタグ付け

1. アクションボタンをクリック、または設定済みホットキーを押す（開始）
2. 同じアクションをもう一度実行（終了）
3. ボタンに設定された「開始前」「終了後」の秒数を含めてタイムラインに追加

## パッケージ管理

### パッケージ作成ウィザード

| ステップ | 内容                                                     |
| -------- | -------------------------------------------------------- |
| 基本情報 | パッケージ名、チーム名                                   |
| 映像     | 最大8アングル、各16ローカルクリップまたはYouTubeクリップ |

映像ステップは、アングル一覧と選択アングルのクリップ一覧による2ペイン構成です。各アングルの「＋」から「ローカル映像」または「YouTube」を選びます。ローカル映像は一度に複数選択でき、Finderから複数ファイルをドロップすることもできます。YouTubeはURLを1本ずつ追加し、同じアングルへ繰り返し追加できます。ローカル映像とYouTubeは同一アングル内で混在できません。追加後のクリップはドラッグまたは上下ボタンで並べ替えられます。

同期位置は作成画面では指定しません。保存先は専用ステップではなく、最後に「パッケージを作成…」を押した時に選択します。

**自動処理**:

- 映像ファイルのコピー＆リネーム
- アングル・クリップ単位の仮想タイムライン作成
- メタデータ生成

作成後にシンクモードを開き、基準クリップと対象クリップをそれぞれ再生・シークして「この位置で配置」を押します。「同期を適用」すると、絶対開始位置と派生した空白時間が保存されます。ローカルアングルも元クリップをそのまま使い、空白区間ではプレイヤーを外して黒画面・無音を表示するため、同期のたびに再生用ファイルを作り直しません。

### パッケージ読み込み

- 最近開いたパッケージがある場合は、ホーム画面のカードから直接再開
- 別のパッケージは「パッケージを開く」または ファイル > 開く > パッケージ… から選択
- `.stpkg` をホーム画面へドラッグ&ドロップして開くことも可能
- 設定とタイムラインは自動復元
- `tightViewPath` / `wideViewPath` だけの旧パッケージも、読み込み時に1アングル1クリップの現行構成へ移行されます。元クリップと旧再生用コピーが併存する場合は元クリップ参照へ切り替わります。安全のため、旧再生用コピー自体は自動削除されません

## 映像再生

### マルチアングル同期

- **表示**: 3アングル以上は映像領域内のグリッドで表示
- **クリップ配置**: 基準クリップと対象クリップの現在位置から、対象クリップの共通タイムライン上の開始位置を計算
- **ローカル映像**: 元クリップを仮想タイムライン上で切り替え、クリップ間の空白を再生時に黒画面・無音で表示。書き出し時のみ一時合成
- **YouTube**: 複数クリップを共通コントローラーとホットキーで操作可能。ネットワーク接続と動画側の埋め込み許可が必要
- **音声で微調整**: ローカル映像は指定区間を解析し、YouTubeを含む場合はmacOS 13以降またはWindowsで表示中の再生音を15秒だけ解析。低信頼度、権限拒否、非対応環境では手動配置を維持
- **手動同期モード**: メニュー「同期 > 手動同期モード」（`Cmd+Shift+T`）
- **同期リセット**: メニュー「同期 > 同期オフセットをリセット」（`Cmd+Shift+R`）
- **再解析**: メニュー「同期 > 自動同期（音声解析）」（`Cmd+Shift+S`）

### 映像ウィンドウと再生バー

再生バーは角丸・半透明の共通UIです。メインの送りは10秒/30秒、Playlistは1秒/クリップ移動、Paintは0.1秒/クリップ先頭・末尾です。Playlistの描画目印をクリックするとその時刻へ移動します。

メイン映像ウィンドウは映像配置の比率を維持します。2映像は横並び、3・4映像は2×2で、サイドバーなどのUI寸法は比率から除外します。Playlistウィンドウは自由に縦横を変更できます。異なる映像比率・3映像の空き枠・フルスクリーンには余白が残る場合があります。

### 再生コントロール

| 操作          | ショートカット       |
| ------------- | -------------------- |
| 再生/一時停止 | `Space`              |
| 0.5倍速逆再生 | `←`（押下中）        |
| 2倍速逆再生   | `Shift+←`（押下中）  |
| 4倍速逆再生   | `Option+←`（押下中） |
| 6倍速逆再生   | `Cmd+←`（押下中）    |
| 0.5倍速再生   | `→`（押下中）        |
| 2倍速再生     | `Shift+→`（押下中）  |
| 4倍速再生     | `Cmd+→`（押下中）    |
| 6倍速再生     | `Option+→`（押下中） |

※ 早送りはキーを離すと通常速度（1.0x）に戻り、逆再生はキーを離した位置で一時停止します。

再生Toolbarは補助操作のための表示です。主要な再生・Coding操作は設定済みショートカットキーから同じruntime処理を実行できます。

## イベントタグ付け

### 基本操作

1. **開始**: アクションボタンを1回クリック、または対応ホットキーを押す
2. **終了**: 同じアクションを2回目実行
3. **保存**: 設定された記録範囲を含めて自動保存

### 記録範囲（Sportscode方式）

Action buttonごとに次の2値を設定できます。

- **開始前に含める秒数**: 開始操作より前の映像をTimeline eventへ含める
- **終了後に含める秒数**: 終了操作より後の映像をTimeline eventへ含める

例: 10:00で開始、10:08で終了し、開始前5秒・終了後3秒の場合、Timelineには09:55〜10:11が記録されます。未設定の既存Code Windowはどちらも0秒として従来どおり動作します。

この設定はボタンクリックだけでなく、同じCode Window buttonへ割り当てたホットキーから開始・終了した場合にも適用されます。記録開始時点の設定値を使うため、記録中に設定を変更しても進行中イベントの範囲は変わりません。

### コーディングパネル編集

**自由配置エディタ（FreeCanvasEditor）**:

- ドラッグ&ドロップで自由配置
- `Shift`/`Cmd`+クリックで複数選択
- グリッドスナップ（10px）
- キャンバスサイズ調整（400-2000px × 300-1500px）

**リンク作成**:

1. 右クリック+ドラッグでリンク作成
2. リンク種別選択:
   - `exclusive`（赤）: 排他的遷移
   - `activate`（緑）: アクティベート
   - `deactivate`（オレンジ）: ディアクティベート
   - `sequence`（青）: シーケンス
3. `Delete` キーで削除

**Undo/Redo**:

- `Cmd+Z`: 元に戻す
- `Cmd+Shift+Z` / `Cmd+Y`: やり直し

## タイムライン編集

### テーブル表示

- ソート機能（アクション名、時刻）
- インライン編集（結果、種別、修飾子）
- 映像ジャンプ（開始/終了時刻ボタン）
- 複数選択削除

### ビジュアルタイムライン

- 映像パッケージを開くと、映像ウィンドウとは別にタイムラインウィンドウが開きます。2画面へ分けて配置できます
- タイムラインを閉じた場合は、メニューバーの「ウィンドウ > タイムラインを開く」から再表示します。映像上には再表示専用の常設ボタンを置きません
- 再生、速度変更、前後シークなどの設定済みホットキーは、映像とタイムラインのどちらにフォーカスがあっても同じ映像へ作用します
- 赤い再生ヘッドは、上部のつまみをドラッグして移動します。目盛りや行内の赤い線を通常クリック・ドラッグしてもシークしません。つまみにフォーカスして左右キー（Shift併用で10秒）、Home/Endでも操作できます
- アクションの選択・開始/終了時刻の変更では再生位置を動かしません。映像は再生中なら通常どおり進みます。明示的な移動は右クリックのジャンプ、再生ツールバー、設定済みホットキーを使います

**ズーム**:

- ウィンドウ下部フッター右側の `− 100% ＋` で表示倍率を変更
- `Cmd/Ctrl` + ホイールでもズーム可能
- 最小倍率は100%、最大倍率は1000%

**範囲選択**:

- アクションのない箇所をクリックすると、選択したアクションとフォーカス枠を解除
- タイムラインの空いている領域をドラッグすると範囲選択
- `Shift` / `Cmd` / `Ctrl` を押しながら範囲選択すると、現在の選択へ追加

**操作**:

- クリック: アクションを選択（再生位置は維持）
- ダブルクリック: 編集ダイアログ
- 右クリック: コンテキストメニュー
- `Enter`: 編集
- `Delete`/`Backspace`: 削除
- ウィンドウ下部フッター左側の`＋`: 空の行を追加
- 行ヘッダーをクリック: 行を選択。`Command`クリックで複数の行を選択
- 行ヘッダーをドラッグ、または右クリックメニューの「上へ移動」「下へ移動」: 行を並べ替え
- 上部の並べ替えメニュー: 色・名前・インスタンス数で行をまとめて並べ替え
- 選択行で`Delete`/`Backspace`、または右クリックメニューの「行を削除」: 確認後に行と所属インスタンスを削除
- 行ヘッダーで`Enter`、ダブルクリック、または右クリック: 行名と色を編集
- インスタンスを別行へ通常ドラッグ: 移動先の行へ移動。`Option`/`Alt`を押しながらドラッグするとコピー
- インスタンスを選択して`Command+C`、貼り付け先の行を選択して`Command+V`: 元の時間位置のまま当該行へコピー
- macOSは `Option+Command`、Windowsは `Alt+Ctrl` + 行内の赤い線の位置からドラッグすると、その行にインスタンスを作成。赤い線は現在の再生位置に残り、作成範囲だけを表示
- 選択中インスタンスの端を、macOSは `Option+Command`、Windowsは `Alt+Ctrl` + ドラッグすると、開始・終了時刻を調整。ドラッグ中はプレビューし、マウスを離して確定すると1回のUndoで戻せます。Esc・修飾キーを離す・ウィンドウからフォーカスを外すと未確定の変更を取消します

UI上に常時説明を出していない高度操作は、ヘルプ > SporTagLytics ヘルプ > タイムライン編集 から検索・確認できます。

### 検索・フィルタ

- テキスト検索
- チーム別フィルタ
- アクション種別フィルタ

### タイムラインのクリップ書き出し

- ファイル > エクスポート > 映像クリップ（オーバーレイ付き）を選択
- 書き出し範囲（全体/選択中）と出力モード（1ファイル/インスタンス/アクション）を指定
- アングル（全アングル/単一/マルチ）を選択
- オーバーレイ設定は「設定 > 一般 > クリップ書き出しオーバーレイ」に従います
- 書き出しを開始すると設定ダイアログは閉じ、専用の進捗ウィンドウが開きます。進捗ウィンドウはメインウィンドウのフォーカスを奪わず、書き出し中も再生などの操作を継続できます
- 書き出しに失敗した場合は、元映像の場所・保存先の書き込み権限・空き容量を確認し、必要に応じて「エラー詳細を表示」から技術情報を確認します

## 統計分析

### 自動イベント検出

自動イベント検出は統計結果を自動生成する機能ではなく、手動分析を早く始めるために通常のTimelineを初期Codingする機能です。

**開き方**:

- メニューバー → `分析 > 自動イベント検出…`

**使い方**:

1. 利用可能なローカル検出モデルを選択
2. 解析するローカル映像アングルを選択
3. 検出対象event、追加先Timeline名、開始前・終了後の秒数を確認
4. `検出してタイムラインへ追加` を実行
5. confidence閾値未満と既存Timelineとの重複を自動除外
6. 残ったeventが通常のTimelineへ一括追加される
7. 以降は通常どおり範囲修正、削除、ラベル付け、Dashboard/Matrix/Playlist分析を行う

複数eventの自動追加は1つの履歴操作として扱われるため、直後であれば1回のUndoでまとめて戻せます。

モデルが利用できない場合、ダイアログにはその旨が表示され、検出は実行できません。モデルのstatus、品質基準、配置、開発者向け評価方法は [自動イベント検出](event-detection.md) を参照してください。

### 統計・分析ウィンドウ（`Cmd+Shift+A`）

v0.4.0以降、統計・分析機能は独立したウィンドウで表示されます。

**現在のタブ（v0.5.0）**:

| タブ           | 内容                                                  | バージョン |
| -------------- | ----------------------------------------------------- | ---------- |
| ダッシュボード | カスタマイズ可能なウィジェット配置、テンプレート管理  | v0.4.0     |
| モメンタム     | ポゼッションの流れを棒グラフで可視化                  | v0.2.0     |
| クロス集計     | 任意の軸でヒートマップ表示、ドリルダウン              | v0.2.0     |
| AI分析         | ローカルLLMによるTimelineデータ分析、推奨クリップ生成 | v0.5.0     |

自動イベント検出は上記のLLM `AI分析` とは別機能です。映像からevent位置を見つけてTimelineへ追加する処理であり、LLMによる分析文生成には使用しません。

**注**: ポゼッション・アクション結果・アクション種別タブはv0.4.0でダッシュボード機能に統合されました。これらの統計情報はダッシュボードのウィジェットまたはカスタムチャート機能で利用できます。

### クロス集計

**カスタマイズ可能な軸**:

- 行軸/列軸: アクション名、結果、種別、修飾子
- フィルタ: チーム別、アクション別
- 画面表示では文字サイズをコンパクト化し、同時に見える情報量を増やしています
- 2段ヘッダ時のスクロール固定を調整し、「合計」列だけ縦長に見える崩れを抑制しています

### ダッシュボード（v0.4.0以降）

**機能**:

- カスタマイズ可能なウィジェット配置
- デフォルトテンプレート（.stadパッケージ形式）
- シリーズ比較機能
- カスタムチャート作成
- 編集モード中はヘッダ操作を `チャート追加 / キャンセル / 保存` に集約し、管理操作とダッシュボード切替は一時的に無効化されます

### モメンタム

- 0基準線が画面中央に見えるよう、Y軸幅を考慮した左右余白で表示します
- 画面表示の目盛りは最小構成（`-max / 0 / +max`）にし、詳細はツールチップで確認します

### AI分析（v0.5.0以降）

**概要**:

AI分析機能は、ローカルLLM（llama.cpp）を使用してTimeline・ラベル・メモ・統計データを分析し、質問に対する回答や推奨クリップを生成します。LLM自体が映像フレームを直接判定する機能ではありません。

詳細なセットアップとトラブルシュートは [AI Analysis and Local LLM Setup](ai-analysis.md) を参照してください。データ境界は [Privacy and Data Handling](privacy-and-data-handling.md) にまとめています。

- 右カラムは `根拠 / イベントインサイト（統計） / AI設定` のAccordion構成です（初期表示は根拠のみ展開）
- 根拠リストは初期表示を上位12件に制御し、必要に応じて全件展開できます
- 右カラム専用スクロールを廃止し、タブ全体で一貫したスクロール動作になります

**必要なセットアップ**:

macOS / Windows配布版にはllama.cppを同梱します。GGUFモデルは別途用意し、AI設定に絶対パスを指定するかユーザーデータの `llama/models/` に配置します。検索順序と開発版の配置は[AIセットアップ](ai-analysis.md)、Windowsの導入は[Windows版](windows.md)を参照してください。

**使い方**:

1. 統計・分析ウィンドウを開く（`Cmd+Shift+A`）
2. 「AI分析」タブを選択
3. テンプレートから質問を選択するか、自由にテキスト入力
4. 「実行」ボタンでAI分析を開始
5. 結果として以下が表示されます：
   - **要約**: 質問に対する簡潔な回答
   - **仮説**: データに基づく推論
   - **根拠**: タイムライン上の関連イベント（ハイライト表示）
   - **推奨クリップ**: AI が選んだ重要シーン

**プレイリスト作成**:

- 「プレイリスト作成」ボタンで、推奨クリップから自動的にプレイリストを生成できます
- 生成されたプレイリストは新しいウィンドウで開きます

**AI分析の仕組み**:

- **ハイブリッド根拠検索**: テキスト、ラベル、メモ、時間、レアラベルを組み合わせて関連イベントを抽出
- **グラウンディング**: タイムラインデータを基にした事実ベースの回答生成
- **ローカル処理**: 全てのデータはローカルで処理され、外部に送信されません
- **ストリーミング進捗**: 出力文字数とチャンクごとの進捗がリアルタイムで表示
- **タイムアウト制御**: デフォルト120秒（2分）、実行中のキャンセルも可能

**制限事項**:

- モデルファイルは `.gguf` 拡張子が必要。重みはアプリに同梱しません
- 環境変数 `SPORTAGLYTICS_LLAMA_PATH` または `LLAMA_CPP_PATH` でバイナリパスをカスタマイズ可能

### 分析結果の出力

分析ウィンドウの export 操作から以下を出力できます。

| 出力                   | 内容                                                   |
| ---------------------- | ------------------------------------------------------ |
| 構造化サマリーをコピー | 現在の分析ビューの要約をクリップボードへコピー         |
| PNG保存                | 現在の分析ビューを画像として保存。長い内容は分割保存可 |
| 分析レポートPDF保存    | ダッシュボード、モメンタム、クロス集計をPDF化          |

詳細は [Analysis Report Export](analysis-report.md) を参照してください。

## プレイリスト機能

### プレイリスト作成

#### タイムラインからの追加（v0.2.0以降）

1. タイムラインからイベントを選択（複数選択可）
2. 右クリック → 「プレイリストに追加」
3. 開いている全てのプレイリストウィンドウに追加されます  
   （ウィンドウが開いていない場合は新規ウィンドウが自動で開きます）

- ツールバーのプレイリストボタンからも同じ操作が可能です
- 選択中のイベントは `Cmd+Shift+P` でもプレイリストに追加できます

#### AI分析からの追加（v0.5.0以降）

1. 統計・分析ウィンドウで「AI分析」タブを開く
2. 質問を入力し「実行」ボタンで分析
3. 「プレイリスト作成」ボタンで推奨クリップからプレイリストを自動生成
4. 新しいプレイリストウィンドウが自動的に開きます

**注意**: v0.5.0でプレイリスト作成方法が統一され、両方の方法とも同じElectron APIを使用するようになりました。

#### 複数ウィンドウ管理

- 同時に複数のプレイリストウィンドウを開くことができます
- 新しいウィンドウは自動的にカスケード表示されます（前のウィンドウから50pxずつオフセット）
- 同じ`.stpl`ファイルを複数回開こうとした場合は、既存のウィンドウにフォーカスします

### プレイリストファイル（.stpl）形式

プレイリストは `.stpl` 拡張子のパッケージ形式で保存されます。

**パッケージ構造**:

```text
MyPlaylist.stpl/              # パッケージディレクトリ（Finderでは単一ファイルに見える）
├── playlist.json             # プレイリストメタデータ（テキストファイル）
└── videos/                   # 映像ファイル（埋め込み形式のみ）
    ├── パス_01JGXXX123ABC/   # <アクション名>_<itemId>
    │   ├── angle1.mp4        # プライマリ映像
    │   └── angle2.mp4        # セカンダリ映像（存在する場合）
    ├── シュート_01JGXXX456DEF/
    │   ├── angle1.mp4
    │   └── angle2.mp4
    └── ...
```

**形式の種類**:

- **埋め込み形式（embedded / スタンドアロン）**: 映像ファイルをFFmpegで切り出して`videos/`に保存、パッケージ単体で再生可能（大容量）
- **参照形式（reference）**: 外部映像ファイルへのパスを保存、軽量（元の映像ファイルが必要）
  - 元映像が移動/削除された場合、参照形式のプレイリストは再生できません

**保存時の選択**:

- 初めてプレイリストを保存する際、保存ボタンを押すと形式選択ダイアログが表示されます
- 既に保存されているプレイリストは、その形式で上書き保存されます
- 埋め込み形式では、クリップの開始時刻は`0秒`起点に変換されます（切り出し動画のため）

**ファイルの閲覧**:

1. Finderでプレイリストファイルを右クリック
2. 「パッケージの内容を表示」を選択
3. `playlist.json` をテキストエディタで開いて内容確認・編集可能

**未保存変更の管理**:

- ウィンドウタイトルに未保存変更がある場合は `*` マークが表示されます
- ウィンドウを閉じる際、未保存の変更がある場合は確認ダイアログが表示されます
  - 「保存」: 変更を保存してから閉じる
  - 「保存しない」: 変更を破棄して閉じる
  - 「キャンセル」: 閉じずにウィンドウを維持
- 保存した描画・フリーズ設定はプレイリスト読み込み時に復元されます

### プレイリストウィンドウ

**Workspace**:

- 上部の **Organizer / Sorter** で、同じプレイリストを presentation 構造または metadata 表として切り替えます。切替、Inspector、splitter、Sorter の検索・sort は保存済みの再生順を変更しません。
- **Organizer** は row ごとに clip を横方向へ並べます。クリックで選択、`Cmd/Ctrl`+クリックで追加選択、`Shift`+クリックで範囲選択、ダブルクリックで再生します。selected と playing は別の表示です。
- **Sorter** は比較・検索用の高密度 table です。列見出しの sort は一時的な表示順です。sort を解除すると presentation order に戻り、export / playback の順序も変わりません。
- Review Area と Workspace の境界はドラッグできます。右上の Inspector では選択中 clip の開始・長さ・labels・note・freeze / drawing・映像情報を確認できます。

**再生機能**:

- 連続再生
- ループ再生
- フリーズフレーム
- アングル表示切替（アングル1/アングル2/デュアル）
- 一時停止後の再生は現在位置から再開し、アイテム行の再生操作はそのクリップ開始位置から再生
- シーク位置は選択中クリップの開始・終了範囲内へ制限

**フリーズの挙動**:

- 描画のタイムスタンプに到達すると自動停止
- 設定したフリーズ時間の経過後に自動再開。再生ボタン/`Space`ですぐ再開することも可能

**コントロール表示**:

- 角丸・半透明の共有再生バーで再生・シーク・速度を操作します
- 描画のある時刻はシーク領域の目印から移動できます。ウィンドウの縦横比は自由に変更できます

**描画とメモ**:

- Paintでは図形のスタイル・位置・表示時間を編集し、動く図形や追尾を作成できます。操作は下の「Paintで映像に描画する」を参照してください。
- アングルごとに描画を保持します。静止注釈と動画中の描画は別の表示方法です。
- メモはプレイリスト内のみに保存され、タイムラインには反映されません。
- 通常レビューでは選択したクリップをBackspace/Deleteで削除できます。Paint中は位置キー・描画の削除へ切り替わります。

### クリップ書き出し

**書き出しモード**:

- 1ファイル: 全クリップを結合
- インスタンスごと: イベント単位
- アクションごと: アクション種別単位

**書き出し範囲**:

- 全体
- 選択中アイテムのみ

**オーバーレイ**:

- アクション名、通番、ラベル、メモ
- 描画（アノテーション）とフリーズフレームを含めた書き出しに対応

**アングル**:

- 全アングル（アングルごとに個別書き出し）
- 単一アングル
- マルチアングル（2映像を並列）

**進捗表示**:

- 書き出し中は専用の進捗ウィンドウが表示されます
- メインウィンドウには進捗バーを出さず、書き出し中も通常操作を継続できます
- 進捗率と残り時間は、各クリップの完了件数ではなくFFmpegが処理した映像時間に追従します
- 失敗時はユーザー向けの確認事項を先に表示し、FFmpeg等の技術情報は「エラー詳細を表示」から展開できます

### Paintで映像に描画する

Playlistでクリップを選び、ツールバーのPaintに切り替えて一時停止します。左でツールを選び、映像上で作成・修正します。右のスタイル・動き・ピッチ・素材で設定し、パネルは上部の矢印から折りたためます。プレゼンは説明に必要な操作へ絞った表示で、描画と履歴を共有します。

選手リンクは足元を順にクリックし、Enterで確定します。自動追尾は「対象を指定して追尾」から描画とは別に選手の上半身を囲みます。位置は下部タイムラインの◆を選択して編集します。Backspace/Deleteは、◆選択時には位置キー、描画選択時には描画全体を削除し、Paint中にクリップを削除しません。開始点は位置だけを編集できます。

[Paintの操作・ショートカット・保存契約・制約](tactics.md)を参照してください。芝色による選手の背後への合成、平面較正、追尾の部分適用、Undoと書き出しの対応範囲も同書を正本とします。

## 設定

### 全般設定

- テーマ（ライト/ダーク/システム）
- クリップ書き出しオーバーレイ（表示/非表示、表示項目の切替）

### コードウィンドウ

- メニューバーの「ファイル > 新規 > コードウィンドウ…」（`Cmd+Shift+N`）から保存先を選び、空の `.stcw` を独立ウィンドウで開く
- 既存ファイルは「ファイル > 開く > コードウィンドウ…」（`Cmd+Option+O`）で対象の `.stcw` を選んで開く
- ボタン配置・プロパティ・リンクの編集と保存は、コードウィンドウ上部の「編集」から行う
- Action buttonの「基本」設定で「開始前に含める秒数」「終了後に含める秒数」を設定できる。クリックとホットキーの両方へ同じ値が適用される
- コード／ラベル／編集モードは対象のコードウィンドウ上部で切り替える。アプリ全体のメニューバーからは切り替えない
- 編集中もボタンの色、輪郭、文字サイズ、位置と寸法は実行時と同じ表示になる。選択中だけ編集用の輪郭とハンドルが追加される
- ウィンドウをリサイズしても保存キャンバスの寸法は変わらず、表示領域を超える場合はスクロールして編集する
- 設定画面は `.stcw` ファイルの管理に使用しない

### メニューバー

- 「ファイル」はパッケージとコードウィンドウの新規作成・選択、最近開いたパッケージ、インポート・エクスポートを扱う
- 「分析」は自動イベント検出を開く
- 「ウィンドウ」はタイムライン・分析・プレイリストの表示と、最小化・ウィンドウ拡大/縮小・前面表示を扱う
- Timelineの `− 100% ＋` はTimelineの表示倍率であり、「ウィンドウ > ウィンドウを拡大/縮小」とは別の操作です
- コードウィンドウは新規作成または `.stcw` 選択を起点とするため、対象が不明な「コードウィンドウを開く」は表示しない
- 「ヘルプ > SporTagLytics ヘルプ」では、UIに常時露出していない高度操作も検索できます

### ホットキー設定

- カスタムホットキー登録
- 機能名またはキーによる検索
- 競合チェック
- デフォルトに戻す
- システム標準のショートカット（Cmd+Q等）は割り当て不可

## プライバシーとデータ

SporTagLytics は local-first の desktop app です。映像、タイムライン、プレイリスト、AI 分析プロンプト、自動イベント検出の映像処理はローカルで行います。現行実装では cloud sync、telemetry、remote analytics、cloud LLM provider を使いません。

保存場所、recent package、localStorage、AI 分析時の一時ファイル、issue 報告時の注意点は [Privacy and Data Handling](privacy-and-data-handling.md) を参照してください。自動イベント検出のrunner protocolと品質ゲートは [自動イベント検出](event-detection.md) を参照してください。

## トラブルシューティング

### 自動イベント検出を実行できない

1. `分析 > 自動イベント検出…` を開く
2. 利用可能なモデルが表示されない場合は、対応するmodel packが導入されているか確認
3. モデルのstatus・品質基準・配置方法は [自動イベント検出](event-detection.md) を参照

### 音声同期がうまくいかない

1. 両映像に音声が含まれているか確認
2. 手動オフセット調整を試す
3. メニュー「同期 > 自動同期（音声解析）」を実行して再計算
4. エラーが表示された場合は、ユーザー向けの対処方法を確認し、必要な場合だけ「エラー詳細を表示」を展開

### 映像が再生されない

1. 元ファイルが移動・削除されていないか確認
2. ファイル形式・コーデックを確認
3. アプリから参照できる場所にファイルが存在するか確認

### 映像を書き出せない

1. 元映像のファイルが存在するか確認
2. 保存先の書き込み権限と空き容量を確認
3. 進捗ウィンドウの対処方法を確認
4. 原因調査が必要な場合は「エラー詳細を表示」を開き、FFmpeg等の技術情報を確認
5. 問題を修正後、メイン画面からもう一度書き出す

### タイムラインが保存されない

1. ディレクトリの書き込み権限を確認
2. ディスク容量を確認
3. `timeline.json` が破損している場合は削除して再作成
