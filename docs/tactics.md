# Paint: 映像への描画・追尾・位置編集

Playlistの描画編集モードの表示名は **Paint** です。本書を操作・制約・保存契約の正本とします。`studio` ディレクトリや内部mode値、`Tactics*` 型名は内部識別子であり、表示名とは分けます。

## 画面とモード

Playlistでクリップを選択し、ツールバーからPaintを開きます。通常レビューと同じ映像を使い、切替のために動画DOMを複製しません。編集は一時停止中に行います。

| 場所                 | 用途                                             |
| -------------------- | ------------------------------------------------ |
| 左パレット           | 選択・描画・選手のツール                         |
| 映像上               | 描画作成、移動、拡縮、リンク各点の調整           |
| 右パネル「スタイル」 | 色、太さ、不透明度、文字、サイズ、図形固有設定   |
| 右パネル「動き」     | 動画中の表示、表示時間、現在位置の記録、自動追尾 |
| 右パネル「ピッチ」   | 平面較正、距離、芝色による前後合成               |
| 右パネル「素材」     | 図形プリセット、プレゼン用ツール・色             |
| 映像下部             | 再生、時間目盛り、描画の表示区間、◆の位置キー    |

右パネルの上部矢印で折りたたみ・再表示できます。選択・設定・Undo履歴は維持し、閉じている間は40pxの再表示操作だけを残します。

「プレゼン」は説明時にツールと色を絞り、右パネルと描画時間軸を隠す表示です。描画データと履歴は編集モードと共有します。「この場面を消去」は現在の時刻・アングルだけを対象にします。

## 描画を作成・修正する

線、矢印、曲線矢印、矩形、楕円、領域、自由描画、テキスト、選手ビーム、ディスク、リング、スポットライトを使用できます。ツールを選んでドラッグすると作成し、完了後は選択ツールへ戻ります。図形の中心をドラッグして移動、選択枠のハンドルで拡縮します。ビームとディスクには名前・背番号を付けられます。

ドラッグは押した地点から離した地点までを1操作として確定します。短いドラッグでも終点を取り込み、一時停止直後の微小な再生時刻更新では破棄しません。明示的なシーク、クリップ・アングルの切替、再生開始、操作取消では未確定の描画を破棄します。

選手リンクは、各選手の足元を順にクリックして2〜15点を配置します。Enterまたは「リンクを確定」で1回の履歴として保存し、Escで未確定の配置を破棄します。選択後は中心点を個別にドラッグできます。「選手を追加」は最も長い区間の中点に追加し、「末尾を削除」は最後の点を除きます。追加後は足元へ移してください。人数を指定するプルダウンはありません。

静止注釈は描画時刻で映像を一時停止して提示します。動画の上で動かすには「動き」の「映像中に表示する」を有効にし、表示時間を指定します。シーク後に図形を移動するか「位置を記録」を押すと、その時刻の位置を保存します。点間は線形補間します。

## タイムラインで位置キーを編集する

1. 描画行の◆を選択します。点と描画の選択は別の状態です。
2. 横ドラッグまたは左右キーで時刻を変更します。ドラッグ中のEsc・フォーカス離脱では未確定の移動を取消します。左右キーは1/30秒、Shift併用は10/30秒の固定刻みで、動画fpsに連動するフレーム送りではありません。
3. タイムライン上部の時刻・X/Y移動量は、数値入力後にEnterまたはフォーカスを外して反映します。Escで入力を取消します。空欄・不正な値・未変更の入力では保存せず、元の値を保ちます。X/Yは基準座標からのオフセットです。
4. 「位置を削除」またはBackspace/Deleteで選択した点だけを削除します。削除後は前の点を選択します。

点は隣のキーを越えず、表示区間外へも動かせません。相対0秒の開始点は保存データの基準なので、位置は編集できますが削除・時刻変更はできません。密集した点は最大16倍に拡大でき、選択点が見える位置へスクロールします。表示時間を短縮すると範囲外のキーを除去し、終端位置を補間して記録します。

| 操作対象                           | キー                         | 動作                                        |
| ---------------------------------- | ---------------------------- | ------------------------------------------- |
| 選択中の◆                          | Backspace / Delete           | 位置キーを削除                              |
| キャンバス・レイヤーで選択した描画 | Backspace / Delete           | 描画全体を削除                              |
| 描画                               | 矢印 / Shift+矢印            | 1 / 10基準座標単位で位置を修正              |
| 編集                               | Cmd/Ctrl+Z、Cmd/Ctrl+Shift+Z | Undo / Redo                                 |
| 描画                               | Cmd/Ctrl+D                   | 複製                                        |
| ツール                             | V / P / A / R / O / T        | 選択 / ペン / 矢印 / 矩形 / 楕円 / テキスト |
| 未確定の操作                       | Esc                          | 中止して選択へ戻る                          |

PaintではPlaylistのクリップ削除、クリップ移動、矢印による速度変更のグローバルホットキーを無効にします。保存・書き出し・Undo/Redo・再生停止は維持します。文字入力欄は通常の文字編集を優先し、再生中・未選択時のBackspaceでクリップを削除しません。

## 自動追尾

1. 動かす描画を選び、開始したい時刻で一時停止します。
2. 「対象を指定して追尾」を押し、映像上で選手の上半身を囲みます。芝や隣の選手を避けます。ディスクの大きさを変更する必要はありません。
3. 「この範囲を追尾」で解析します。解析中は中止できます。
4. 成功すると位置キーを自動反映します。途中で見失った場合は、追尾できた範囲を明示的に適用するか破棄します。
5. 外れた時刻で位置を手修正し、対象範囲を指定し直して再開できます。それより前のキーは維持します。

対象範囲は解析ごとの一時状態で、クリップ・選択・時刻・編集可否の変更で破棄します。保存する図形とは独立した正規化座標を解析解像度へ変換します。詳細な判断は[ADR 0031](adr/0031-tracking-target-selection.md)。

解析は別の動画デコーダーを使い、主映像をシークしません。範囲内の輪郭・模様から最大10点を選び、大小のパッチの往復照合・移動の一致・半解像度での再探索を使用します。再探索範囲は追跡変位に合わせて移動します。解析中に描画が変わった場合は結果を上書きしません。

小さな移動の丸め誤差が蓄積しないよう、局所照合の位置を解析画像の0.01ピクセル単位まで絞り込みます。これは追尾精度の保証値ではありません。再生中の描画と芝色合成は、各アングルが実際に表示するフレームの時刻で更新します。図形の位置は選手に対して最初に置いた位置を基準とし、自動で足元へ吸着する機能ではありません。

人物の意味的識別、遮蔽後の再識別、全選手の自動検出ではありません。無地、急な変形、似た選手の交差、カメラ移動では停止・誤追尾があり得ます。選手リンクを追尾するとリンク全体を平行移動し、各選手を個別追跡しません。

## 選手の背後への合成

そのアングルで最初のディスク・リング・ビーム・選手リンクを追加すると、芝色を抽出して背後合成を有効にします。描画と芝色設定は同じUndo履歴で保存します。既存の描画は「選手の背後に描画」から芝色の抽出・色の範囲調整・解除ができます。解除後に同じアングルへ図形を追加しても、既存の選手図形がある間は自動で再有効化しません。

映像の芝色に近い部分だけ描画を残す処理であり、人物の輪郭を認識して切り抜く機能ではありません。設定はアングル内の描画全体に作用し、プレビュー・動画書き出しで共有します。緑のユニフォーム、照明変化、芝以外の床では手動調整が必要です。映像の色を取得できない場合は解除・再抽出を案内します。

## 平面較正と素材

「ピッチ」で既知の長方形の4隅を周囲の順に指定し、幅・長さを入力します。点はドラッグと矢印キーで調整できます。同一平面への領域投影と線・矢印の概算距離を表示します。カメラが動いた場合は再較正が必要です。距離数値と較正ガイドは編集補助で、映像には焼き込みません。

「素材」では単一図形の形・スタイルを保存し、現在時刻に挿入します。動きはプリセットへ含めません。プリセットとプレゼン設定は端末のローカル設定であり、Playlist文書の共有には含まれません。

## 保存契約と上限

| 項目       | 現行契約                                                                               |
| ---------- | -------------------------------------------------------------------------------------- |
| 型の正本   | `src/types/playlist/core.ts` の `DrawingObject` / `ItemAnnotation`                     |
| 動画描画   | `motion.duration` と相対秒の `keyframes`。最大600秒、256キー / 図形                    |
| 位置       | `baseWidth` / `baseHeight` 上の平行移動量。回転・拡大率・形状の時間変化は未対応        |
| 注釈時刻   | 参照動画のソース時刻。埋込クリップでは保存時にクリップ開始を差し引き、編集表示時に戻す |
| 追尾       | 1回最大20秒、30Hz、解析幅最大1280px。結果は線形補間の誤差1px以内で間引く               |
| 書き出し   | 動き/芝色処理は1クリップ64図形、合計4096キーまで                                       |
| 芝色・較正 | `ItemAnnotation` のアングル別メタデータ                                                |
| 素材       | 端末内で最大24件                                                                       |

位置キーの時刻は昇順、先頭は0秒、表示区間内で有限値とします。不正な拡張データは読込エラーにし、静止図形へ黙って変換して保存しません。従来の静止注釈は引き続き読み込めます。保存・動画合成の判断は[ADR 0029](adr/0029-tactics-motion-and-plane-contract.md)を参照してください。

## 映像への書き出し

Playlistの書き出しでは、静止図形・追尾図形・芝色処理とアングルを反映します。クリップの開始位置より前に追尾が始まっていても、クリップと重なる部分を出力し、開始位置は保存済みキーから補間します。元の描画や位置キーは書き換えません。

図形は元映像の時刻で合成した後にフリーズを挿入します。フリーズ中は映像と図形が一緒に停止し、音声は無音になります。再開後は描画と音声を同じ元映像時刻から継続します。静止描画が複数の時刻にある場合は、それぞれの時刻へ停止時間を追加します。

図形のPNG生成に失敗した場合や位置キーの上限を超えた場合は、描画を欠いた動画を成功扱いにせずエラーを表示します。出力アングルとまとめ方は[Playlistの書き出し](playlist-features.md#映像の書き出し)を参照してください。

## 実装と検証の入口

- `src/features/playlist/studio/useStudioEditor.ts`: 編集の合成・選択・履歴callback・キー操作。
- `useStudioGesture.ts`: 描画・リンク配置の一時状態と1操作1履歴。
- `useStudioKeyframes.ts`: 点の選択、順序を保つ時刻編集、削除対象の分離。
- `tracking/`: 別デコーダー、特徴点照合、解析の取消と結果適用。
- `src/shared/tactics/`: 補間、検証、芝色、平面計算。
- `src/features/playlist/components/annotationDrawing.ts` / `tacticalDrawing.ts`: 共通Canvas描画。
- `src/features/playlist/utils/playlistMotionExport.ts` と `electron/src/ipc/exportChroma.ts`: 動画出力への変換・合成。

Storybook `Workspace/Playlist/Paint` の Interactive / Empty / Player Graphics / Video Tracking / Keyframe Editing / Inspector Layout / Collapsed Inspector で確認します。合成映像の追尾成功は実試合の精度保証ではありません。実機の保存・再読込・FFmpeg出力と実試合映像での追尾を別々に検証します。
