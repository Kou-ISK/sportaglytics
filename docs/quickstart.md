# 合成サンプルではじめる

自分の試合映像がなくても、開く → 場面を1件追加 → 修正 → 保存して再開 → MP4を1本書き出す、まで試せます。GGUF・event model pack・AI設定は不要です。映像は20秒の図形アニメーションで、人物・音声・実試合は含みません。モデル精度の評価用データではありません。

## 1. サンプルを開く

1. [対応OSのアプリをインストール](../README.md#インストール)します。
2. [synthetic-first-run.stpkg.zip](../samples/synthetic-first-run.stpkg.zip)をダウンロードします。GitHubのファイル画面では **Download raw file** を選びます（約29 KB）。
3. ZIPを展開し、書き込み可能な作業フォルダへ `Synthetic-first-run.stpkg` を置きます。展開したパッケージ全体が作業コピーです。**ZIPのまま開かないでください。** Windowsでは「すべて展開」を使い、`.metadata`・`timeline.json`・`videos`が同じ`.stpkg`内にある状態を保ちます。
4. SporTagLyticsの初回案内を閉じ、開始画面の「パッケージを開く」から`.stpkg`を選びます。開始画面へのドロップも使えます。
5. 緑の背景と動く白い図形、Timelineの「練習 / パス」「練習 / メモ」2行、2〜5秒のタグ1件が見えれば準備完了です。映像を選択してSpaceで再生・停止できます。

## 2. 場面を1件追加し、内容を修正する

最初は既存タグのコピーで追加操作を試します。これはAI検出や自動コーディングではありません。

1. Timelineの「練習 / パス」のタグをクリックし、`Cmd+C`（Windows: `Ctrl+C`）を押します。
2. 「練習 / メモ」の行名をクリックし、`Cmd+V`（Windows: `Ctrl+V`）を押します。同じ2〜5秒の場所にコピーができ、合計2件になります。
3. コピーしたタグをダブルクリックして「アクション編集」を開きます。
4. 「開始秒」を `6`、「終了秒」を `9`、「ノート」を `はじめての練習` にして「保存」を押します。タグが6〜9秒へ移ります。

元の2〜5秒のタグも残っていることを確認してください。間違えた場合はTimelineにフォーカスを戻して`Cmd+Z` / `Ctrl+Z`で取り消せます。新しく時間を記録する操作は[イベントタグ付け](user-guide.md#3-イベントタグ付け)、行・区間の操作は[Timeline編集](user-guide.md#タイムライン編集)を参照してください。

## 3. 保存して開き直す

Timelineは変更を自動保存します。保存エラーが出た場合は閉じず、書き込み権限・空き容量・保存先を確認して再試行してください。「アクション編集」の「保存」は編集の確定操作であり、それだけでディスクへの保存完了を意味しません。

v0.17.11では通常のClose/Quit時に保留中のTimeline保存を待ち、保存できなければ終了を取り消します。エラーを解消してから再試行してください。v0.17.10以前を使用する場合は編集直後の終了を避け、変更内容と保存エラーがないことを確認してください。OS強制終了・停電はこの保存保証の対象外です。使用中の版と[保存契約](package-compatibility.md)を確認してください。

その後、映像ウィンドウを閉じ、開始画面の履歴または「パッケージを開く」で同じ`.stpkg`を開き直します。合計2件、6〜9秒の「練習 / メモ」、ノート「はじめての練習」が残っていることを確認します。

## 4. MP4クリップを1本共有する

1. Timelineの6〜9秒のタグをクリックして1件だけ選択します。
2. メニューバーの「ファイル」→「エクスポート」→「映像クリップ（オーバーレイ付き）」を開きます。
3. 書き出し範囲を「選択インスタンス (1 件)」、出力モードを「単一映像ファイル（連結）」にし、ファイル名を `first-clip` にします。画面の名称は[映像書き出し](user-guide.md#データのインポートエクスポート)も参照してください。
4. テキスト情報を含めるか選び、プレビューを確認して「書き出し」を押します。初回は「含めない」を選ぶと元映像だけを共有できます。
5. 保存先を選び、「書き出し完了」を待ちます。保存先のMP4を動画プレイヤーで開き、約3秒であることを確認します。

サンプルのMP4は共有できます。自分の分析データを共有する場合は、映像・ノート・人物情報の公開範囲を確認してください。編集可能なバックアップには`.stpkg`全体を使います。MP4やCSVはパッケージの完全バックアップではありません。

## うまく進まないとき

| 症状                   | 確認すること                                                              |
| ---------------------- | ------------------------------------------------------------------------- |
| ZIPを選んでも開けない  | ZIPを展開してから中の`.stpkg`を選ぶ                                       |
| 動画が見つからない     | `.metadata`・`timeline.json`・`videos`を分離せず、全体を再展開する        |
| 変更を保存できない     | ZIP閲覧内や読み取り専用の場所を避け、書き込めるフォルダへ全体をコピーする |
| 自動検出のモデルがない | この練習は手動操作のみ。モデルを追加しなくても完了できる                  |
| クリップが6秒になった  | 全2件を出力していないか確認し、6〜9秒の1件だけを選ぶ                      |

## サンプルの由来と再生成（開発者向け）

サンプルと生成スクリプトにはリポジトリの[MIT License](../LICENSE)を適用します。図形・線・動きはスクリプト内の式だけで作成し、外部画像・フォント・人物・試合映像・生成AIサービスを使いません。ZIP内に`LICENSE.txt`と`SAMPLE.txt`を同梱しています。既存の出典未確認アイコンや旧動画fixtureとは別の、新しく再生成可能な資料です。

通常利用にPythonやFFmpegの別インストールは不要です。再生成する場合のみPython 3と`libx264`付きFFmpegを用意し、リポジトリ直下で実行します。

```bash
python3 scripts/generate-synthetic-sample.py --output output/synthetic-sample
python3 scripts/tests/synthetic-sample.py
```

WindowsでPythonを`py -3`として導入している場合は`python3`を置き換えます。出力先が既に存在すると停止し、上書きしません。別の空いている出力先を指定してください。`--ffmpeg /path/to/ffmpeg`または`SPORTAGLYTICS_FFMPEG_PATH`で実行ファイルを指定できます。検査のFFprobeは`SPORTAGLYTICS_FFPROBE_PATH`で指定します。

[samples/synthetic-first-run.manifest.json](../samples/synthetic-first-run.manifest.json)にFFmpeg版、全ファイルのSHA-256、ZIPのサイズとSHA-256を記録しています。ZIPの順序・時刻・権限を固定していますが、異なるFFmpeg/libx264ビルド間の映像バイト一致は保証しません。version表示の先頭行が同じでも同一ビルドとは判定せず、配布ZIPのmanifest整合性と、この実行環境内の連続生成の一致を別々に検査します。レシピの連続2回の一致、元出力の上書き拒否、配布ZIPのhash・相対パス・20秒/H.264/640×360/24fps・全フレームの復号を検査します。

アプリをbuild済みの開発環境では、公開ZIPそのものを使う操作試験も実行できます。

```bash
pnpm run e2e:prepare
node scripts/e2e-synthetic-first-run.mjs
```

Pythonの実行名が異なる場合は`PYTHON`に実行ファイルを指定します。2026-10-18のcloud Linux / Electron 43.5.1 / Xvfb検証では、Openボタンからの読込、20秒映像の復号、コピー追加、ノート・区間編集、実ファイル保存、別プロセス再開、3秒のMP4出力を確認しました。OS pickerの返答のみ模擬し、writer・exportは実処理です。編集のdisk反映を待ってから終了する試験であり、終了直前の保存競合を検証するものではありません。Mac/WindowsのFinder/Explorerや署名・公証検査も代替しません。
