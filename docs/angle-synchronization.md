# アングル同期

この文書は複数映像を含むアングルの手動同期について、操作、時計、保存、制約を定義する正本です。音声相関の仕様は[音声同期オフセット](audio-sync-offset-specification.md)、再生・出力の共通時計は[ADR 0040](adr/0040-shared-media-timeline-clock.md)を参照してください。

## 操作

アングル1のA→Bとアングル2のC→Dは、それぞれ一本の連続した映像として操作します。同期画面でA/B/C/Dを個別に選択する必要はありません。

1. 通常のタイムライン上部の「アングル同期」を押します。メニュー「同期 > 手動同期モード」（`Cmd/Ctrl+Shift+T`）も同じ入口です。再生位置と表示中アングルを引き継ぎ、Codingの行・時間目盛り・赤い再生ヘッドはそのまま使います。
2. 再生時と同じ設定済みホットキー（既定は`Shift+1`）でアングル1を表示します。独立タイムラインの赤いつまみをドラッグし、←/→のコマ送りで同じ瞬間に合わせます。タイムライン上部の「同期点を設定」（Sync Point）またはSキーで指定します。映像ウィンドウに追加のシークバーやアングル選択ボタンはありません。
3. アングル2でも同じ瞬間に同期点を設定します。3アングル以上の場合も、同様に全アングルに設定します。同期点は時間目盛りと映像上の◆で確認できます。「同期のその他の操作 > 同期点を解除」で設定し直せます。
4. 表示中のアングルと同じアングル切替キーで全表示へ戻り、「アングルを同期」（Align Angles）を押します。アングル1を基準として同期点が揃い、全表示になります。再生・シークで同期を確認します。
5. 後半の映像を別に収録した場合は、各アングルを後半までシークし、同じ手順で同期点を設定して同期します。対応する映像のない位置は映像面が黒くなります。元ファイルの切替は自動です。
6. 「保存して閉じる」でまとめて保存します。保存前の同期に戻すボタンは未保存の調整を取り消し、「キャンセル」はパッケージを変更せず閉じます。

同期点を揃えるたびに、その組の一時的な同期点を解除します。別の区間の同期時に前回の同期点を混ぜないためです。映像の長さの読込通知でも、調整済みの配置は保持します。

## キーボードとフレーム

| 操作                                   | キー                                                  |
| -------------------------------------- | ----------------------------------------------------- |
| アングル表示／同じアングルから全表示へ | 設定したアングル切替キー（既定 `Shift+1`〜`Shift+8`） |
| 再生／一時停止                         | `Space`                                               |
| 1コマ戻る／進む                        | `←` / `→`                                             |
| 1秒戻る／進む                          | `Shift+←` / `Shift+→`                                 |
| 表示中のアングルへ同期点               | `S` または `Cmd/Ctrl+Shift+M`                         |
| 保存せず閉じる                         | `Escape`                                              |

キー割り当てと無効化は「設定 > ホットキー」で変更します。同期専用の数字キー割り当てはありません。設定済みのアングル切替キーは同期用のS/矢印より優先します。

タイムライン上部のタイムコードには `分:秒.ミリ秒` または秒数を入力し、Enterで移動します。映像・タイムラインのどちらがフォーカスされていても同じキーを使えます。文字入力中には映像のショートカットを適用しません。同期モードのキーを通常の再生・コード入力・Timeline削除に渡しません。

ローカル動画のコマ送りは、FFprobeで現在位置付近の実フレーム時刻（PTS）を読みます。アプリ共通の30fps換算ではなく、25/50fpsなどの異なるフレームレートや可変フレーム間隔を扱います。先頭PTSが非ゼロでもブラウザーの映像時計と同じ時刻を保持し、元ファイル境界では隣の区間のフレームへ移動します。取得失敗時に推定fpsで成功扱いにせず、再試行を案内します。

YouTubeの埋め込みAPIは実フレーム時刻を公開しないため、正確なコマ送りは提供しません。シーク・再生による同期点設定は可能です。ネットワーク接続・埋め込み許可が必要です。

## 本数の異なるアングルと映像のない区間

同期未設定の取り込みでは、同一アングルの映像を取り込み順に余白ゼロで連続配置します。ファイルの本数や番号で同期相手を固定しません。

例: アングル1に30秒のA、アングル2に10秒のCと5秒のDを取り込みます。初期配置はAが0〜30秒、Cが0〜10秒、Dが10〜15秒です。Aの26秒とDの1秒に同期点を設定すると、Dは25〜30秒へ移動し、Cは0〜10秒のままです。アングル2の10〜25秒は映像も音声も存在しない区間となり、再生・書き出しでは黒と無音になります。Aは全区間を継続して再生します。

タイムラインは既存の再生ヘッドを一つだけ使います。単一アングル表示中のシークはそのアングルの時計だけを動かし、切替時にそのアングルの再生位置をタイムラインへ反映します。全表示でのシーク・同期後の再生は共通時計へ戻ります。

## 同期と保存の契約

- 同期点は `{ clipId, sourceTime }` の一時状態です。アングルをシークして別ファイルに移っても、指定した場面を保持します。
- アングル1の同期点の共通時刻を基準に、他のアングルの同期点を含む区間と、その後続区間を同じ秒数だけ移動します。前の区間を動かさないため、前半を合わせた後に後半の補正を変更できます。
- 同一アングルの前の区間に重なる補正は拒否し、全アングルの調整を変更しません。余分な録画の自動トリムや時計ドリフトの伸縮補正は行いません。
- 先頭が共通時刻の0秒より前になる場合は、既存の `angleOffsets` で先頭の切詰めを表します。`timelineStartSeconds` は非負のまま保持します。
- 「保存して閉じる」は `package:apply-clip-timeline` で配置とアングル補正を同じ設定更新として保存します。`angleOffsets[0] = 0`、最大8アングル、有限値、絶対値24時間以内、配置の重複をMainで検証します。保存失敗時にはワークスペースと未保存調整を保持します。
- メイン再生・参照Playlist・Paint・動画書き出しは同じ保存済み配置を参照します。同期編集のたびに長い連結動画は作成しません。
- 2アングルでは、両方の同期点を置いた後に「音声で微調整」も利用できます。低信頼度や権限拒否で手動調整を失いません。解析中のキャンセルは解析だけを停止します。

## ウィンドウと状態

通常の映像面をアングル同期面に置き換え、背後に重複した動画を残しません。映像ウィンドウはプレビューだけを表示します。同期点・コマ送り・保存は通常のタイムラインの既存ツールバーへ配置し、同期専用のアングル行や別のシークバーを追加しません。音声微調整・同期点解除・リセット・破棄は「同期のその他の操作」にまとめます。1アングルはその映像比率、2アングルは横並び、3〜4アングルは2×2の合成比率を用います。OSのウィンドウ比率は映像面だけを基準とし、ウィンドウの装飾部分を除外します。同期中も縦横比を管理し、固定の420px最低高さを要求しません。

元動画の切替でデコーダーが時計を先頭へ戻した場合は、loadeddata / canplay / seekedでも最新の要求時刻を反映します。シーク完了前のフレームを同期点として記録しません。

読込中は進捗バー、元映像がない位置は空白、ファイル読込失敗はエラーを映像面に表示します。操作はコンパクトな1行にまとめ、選択アングル名を省略表示します。処理結果やエラーはタイムラインのツールバー直下に表示します。映像面の高さは奪いません。ボタン内の文字を折り返しません。画面最大化・異なる映像比率では余白が残ることがあります。Playlistウィンドウを比率固定する変更はありません。

## Hudl Sportscodeとの対応

2026-09-21に、公式Hudl Supportの記事本文と掲載画像で以下を確認しました。通常のCodingタイムラインの上部にSync PointとAlign Anglesがあり、専用のアングル行を追加する構成ではありません。製品比較表やClassicマニュアルだけから操作を推定しません。

- [Align Multiple Angle Timelines](https://support.hudl.com/s/article/aligning-multiple-angle-timelines-sportscode): ホットキーでアングルを切り替え、タイムラインの赤い再生ヘッドで位置を合わせてタイムライン上部のSync Pointを指定し、全表示に戻してAlign Anglesを実行する操作。
- [Align Angles for Video With/Without Halftime](https://support.hudl.com/s/article/aligning-angles-for-video-with-halftime-and-without-halftime-sportscode): 前後半のファイルを同一アングルへ割り当て、それぞれの開始場面で同期を繰り返す操作。
- [Enable Hotkeys for Multi-Angle Playback](https://support.hudl.com/s/article/enable-hotkeys-for-multi-angle-playback-sportscode): アングルごとのキー割り当て。Moviesの設定で割り当てたキーを再生・同期で共用します。SporTagLyticsもホットキー設定のアングル切替を共用します。

公式記事の掲載画像は2019年撮影のものです。現在提供されている操作説明を根拠とし、最新バイナリとの外観の完全一致を確認したという意味ではありません。`Shift+1`〜`Shift+8`の既定値、Sキー、前の区間を保持する処理、保存前ドラフトはSporTagLyticsの実装契約です。

## 実装と検証

- props-only UI: `AngleSyncWorkspaceView`, `AngleSyncPreviewView`, `AngleSyncTransportView`, `SyncTimecodeView`, `TimelineSyncMarkersView`。
- Controller: `useAngleSyncSession` が映像とタイムラインの状態源を共有し、既存の型付きTimeline IPCで操作と表示を同期します。`useAngleSyncDraft`（同期点・配置・保存）、`useAngleSyncTransport`（アングル時計）、`useAngleSyncHotkeys`（両ウィンドウのキー）、`useAngleSyncPreview`（元動画の切替）と`useAngleSyncPreviewClock`（読み込み後の指定時刻への再同期）。計算は `angleSync.ts`。
- Main: `mediaFrameService` の読み取り専用 `media:frame-window`。絶対メディアパス・時刻・senderを検証し、近傍の取得範囲、15秒の実行時間、4MBの出力、キャッシュ件数を制限します。PTSの扱いは[FFprobe公式仕様](https://ffmpeg.org/ffprobe.html#Main-options)に従います。
- Storybook: `Features/VideoPlayer/AngleSync` の単一・2・4アングル、狭幅、空、エラー、保存中。
- `angleSync.test.ts` / `useAngleSyncDraft.test.tsx`: 前後半、4アングル、先頭補正、重複拒否、メタデータ通知、キャンセル。
- `mediaFrameService.test.ts` / `angleSyncPersistence.test.ts`: 可変PTS・キャッシュ・不正入力・配置と補正の同時保存。
- `scripts/e2e-angle-sync-multi.mjs`: 非ゼロ開始PTS・可変フレーム間隔と3/4アングルの実ウィンドウ配置・同期点・保存を確認します。
- `scripts/e2e-multi-clip-playback.mjs`: 25/50fpsの合成映像で、実ウィンドウの比率とボタンの可視性、アングル選択、フレーム送り、同期点、境界切替、保存、Playlist、出力画素を確認します。

- `scripts/e2e-angle-sync-gaps.mjs`: 本数の異なる30秒/10秒/5秒の合成動画で、タイムラインのつまみ操作、別ウィンドウからのコマ送り、0〜10秒/25〜30秒の配置、10〜25秒の黒表示・保存・再読込・書き出し画素を確認します。
