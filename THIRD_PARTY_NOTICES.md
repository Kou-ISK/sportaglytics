## FFmpeg corresponding source

This software uses FFmpeg under LGPL-2.1-or-later. The media build also uses FreeType (FTL) and HarfBuzz; Windows additionally uses OpenH264 and zlib. FreeType is copyright its respective authors as recorded in the included `freetype-FTL.TXT`. macOS system libraries remain OS-provided.

For releases produced with the source-bundle workflow, download `media-tools-sources-<version>.tar.gz` alongside the installers at https://github.com/Kou-ISK/sportaglytics/releases. It contains checksum-verified upstream source archives, the build scripts (including the Windows UTF-8 manifest modification), source hashes, and the pre-signing build manifests for the distributed targets. It contains no models, match footage, or local dataset files. Verify its digest with the release's `SHA256SUMS.txt`. See `docs/third-party-distribution.md` for reproduction and audit limits.

The existing v0.17.3 assets predate this source-bundle workflow. Their release has no corresponding-source attachment as of 2026-10-10. Its exact pinned source URLs/hashes and recipes remain available in that tag under `scripts/media-tools/` and `scripts/build-media-tools.mjs`; this is an outstanding distribution follow-up, not a claim that a source attachment already exists. Existing release binaries/tags are not replaced.
